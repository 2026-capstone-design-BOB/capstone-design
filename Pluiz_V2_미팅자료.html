핵심 차별성
  • ⚡
    코드 생성 + 직접 실행 방식 — 스크린샷 분석 + 마우스 클릭 방식(Claude Computer Use)이 아닌, LLM이 생성한 Python 코드를 로컬에서 직접 실행. 속도가 빠르고 실패율이 낮음
  • 🔒
    AST 기반 보안 레이어 — LLM이 생성한 코드를 실행 전 Python 추상 구문 트리(AST)로 정적 분석. 위험 패턴 자동 차단. 경쟁 시스템 대부분 미구현
  • 🇰🇷
    한국어 구어체 최적화 — "야 크롬 좀 켜봐 ㅋㅋ", "조용히 해줘" 등 구어체/신조어 처리를 Few-shot 프롬프트로 해결. 영어 중심 경쟁 시스템 대비 한국 사용자 UX 우위
  • 💾
    명령 캐싱으로 API 비용 절감 — 성공 코드를 SQLite에 저장, 재실행 시 API 호출 없이 즉시 실행 (~1초). 구독 기반 경쟁 서비스($20~$200/월) 대비 실사용 비용 최소화
  • 🔧
    Windows 시스템 완전 통합 — ctypes Win32 API, PowerShell, WMI, 레지스트리까지 활용. 브라우저/웹 작업만 가능한 Operator와 달리 OS 레벨 제어 가능
