핵심 질문: "API가 다 해주는 거 아니냐?"  —  베이스라인 테스트가 그 답입니다. API 단독으로는 보안·경로·맥락·성능 문제를 해결할 수 없었고, 아래 각 항목은 API 위에 우리가 직접 설계하고 구현한 레이어입니다.
