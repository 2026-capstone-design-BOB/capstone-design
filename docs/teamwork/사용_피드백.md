올라가면 되돌릴 수 없습니다 — 지워도 **기록(커밋 히스토리)에 남습니다.**

## ✍️ 기록 양식 — 복사해서 **아래 「기록」 맨 위에** 붙이세요

```
### ⬜ (한 줄로 — 무엇이 불편했나)

| | |
|---|---|
| **언제** | 2026-__-__ __:__ |
| **누가** | 팀원 A / 팀원 B / 개발자 |
| **어디서** | 조용한 방 / 카페 / 강의실 … |

| **무슨 일이 일어났나** | |
| **뭘 기대했나** | |
| **다시 하면 또 그러나** | 예 / 아니오 / 안 해 봄 |
```

**「다시 하면 또 그러나」가 비어 있어도 괜찮습니다.** 한 번 더 해 보는 게 번거로우면
`안 해 봄` 으로 두세요 — **비워 두는 것보다 「안 해 봤다」가 정확합니다.**

### 💡 불편한 것 말고 이런 것도 적어 주세요

| 표시 | 무엇 |
|---|---|
| `⬜` | 안 되거나 이상한 것 |
| `💡` | *"이런 것도 되면 좋겠다"* — 새 기능 제안 |
| `😕` | 되긴 되는데 **답답하거나 어색한 것** (느리다 · 말투가 이상하다 · 왜 물어보는지 모르겠다) |
| `👍` | **잘 된 것** — 이것도 적어 주세요. 포스터·발표에 **그대로 쓸 재료**가 됩니다 |

> 🔑 `😕` 가 제일 안 적히고 제일 중요합니다. *"되긴 되니까"* 하고 넘어간 것들이
> 2026-09-22 교수님 피드백의 *"실사용성을 본다"* 에 그대로 걸립니다.

### ✅ 같은 날 고친 것 — 왜 저녁 메뉴만 빠졌나

**기록에는 있었다.** `[BL-56] 기록 25줄` = 머리 1줄 + **12턴 × 2줄** 이고, 자른 턴이
있었으면 «빠졌습니다» 한 줄이 더 붙어 26줄이 된다. 즉 **13턴 중 지금 묻는 턴만 빼고
12턴이 전부 들어갔다.**

🔑 **빠뜨린 것은 모델이고, 빠뜨리게 만든 것은 기록의 모양이었다** — 도구를 안 부른 턴을
*"(도구를 부르지 않았습니다)"* 라고만 적어서 **빈칸처럼 보였다.**
→ 이제 **뭐라고 답했는지**를 같이 적고, 지시에 *«도구를 안 부른 턴도 한 일이니 빼지
말라»* 를 넣었다.
