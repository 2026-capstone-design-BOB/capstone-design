## 3. 모인 것 가져오기 (변소윤)

**파일을 주고받지 않습니다.** 사람들이 «보내기»를 누르면 서버에 쌓이고, 아래로 내려받습니다.

```bash
cd scripts/collect-server
npx vercel env pull .env.local  # 처음 한 번만 (전역 설치가 아니라 npx 로 부른다)
npm run pull                    # 🔁 **모인 것을 가져올 때마다** (한 번이 아니다)

cd ../..
python scripts/ingest_wakeword.py --list        # 몇 명 모였나
python scripts/ingest_wakeword.py --holdout 4   # 미학습 화자 4명을 떼고 모은다
```

> 🔒 저장소는 **private** 입니다 — 주소를 알아도 남이 못 듣습니다.
> **목록 API를 일부러 안 만들었습니다.** 그게 곧 «누가 녹음했는지 공개»라서,
> 목록은 위 `npm run pull` 로 **본인 컴퓨터에서만** 봅니다.
> `data/` 는 git에 안 올라갑니다 — 용량 때문만이 아니라 **사람들 목소리**라서요.

### 📎 인터넷이 안 되는 자리에서 받아야 한다면

`scripts/플루이즈_녹음.html` 파일을 보내도 **똑같이 동작합니다.** 다만 그 경우엔
«보내기»가 없고 **파일 2개(`.wav` + `.json`)가 다운로드**되니, 그 둘을 받아서
`data/wakeword_raw/` 에 넣으면 됩니다. **결과 형식은 링크 방식과 완전히 같습니다.**

> 🔑 **같은 파일 하나가 두 모드로 돕니다.** 링크로 열면 «보내기»,
> 파일로 열면 «파일로 받기» — 페이지를 두 벌 관리하지 않습니다.

## 4. 왜 «플루이즈»만 녹음하지 않는가 — 설명을 요구받으면

녹음이 세 부분입니다. 대부분 *"왜 딴 말도 시켜요?"* 라고 물어봅니다.

| | 무엇 | 왜 |
|---|---|---|
| ① | «플루이즈» 20번 (톤·속도·크기를 바꿔서) | 한 가지 톤만 배우면 **그 톤에만** 반응합니다 |
| ② | *"블루투스 어디서 켜"* 같은 **비슷하지만 다른 말** 10개 | 🚨 **아래 참조 — 여기가 핵심입니다** |
| ③ | **주제를 하나 띄워 주고** 15초씩 3번 | 전시회 부스 앞 잡담이 이 분포입니다.<br>*"아무 말이나 하세요"* 는 사람을 얼어붙게 만들어서 **대답할 수 있는 질문**을 띄웁니다 |

### 🚨 ②가 없으면 «아무 말에나 깨어나는» 모델이 됩니다

**2026-09-09에 실제로 겪었습니다.** 실제 녹음을 **양성으로만** 넣고 학습했더니
검증 성적은 멀쩡한데(감지 93.6% · 오탐 2.35%) **실기에서 아무 말에나 깨어났습니다.**

원인은 임계값이 아니라 **데이터 구성**이었습니다. 학습셋에서 «진짜 마이크 소리»가
전부 양성이면, 모델은 단어를 배울 이유가 없습니다 —
**«기계음이냐 진짜 마이크냐»만 구분해도 만점**이기 때문입니다.

그래서 **같은 마이크로 «플루이즈가 아닌 말»** 을 받아야 그 지름길이 막힙니다.

> 📌 *"블루투스 어디서 켜"* 가 목록에 있는 건 **시연 대본 5장면이라서**입니다.
> 발음이 가깝고 **우리가 직접 말할 문장**이라, 빠지면 시연 중 자기 말에 깨어납니다.

## 5. 자주 나오는 질문

**Q. 마이크가 안 켜져요**
→ 브라우저가 물어보는 마이크 권한을 «허용» 해야 합니다. 안 되면 **크롬**으로 열어 주세요.
(휴대폰은 사파리·크롬 둘 다 됩니다.)

**Q. 중간에 틀렸어요 / 기침했어요 / 더듬었어요**
→ **그 항목만 다시 하면 됩니다.** 화면 아래 «↺ 방금 것 다시» 를 누르거나,
끝나고 나오는 목록에서 해당 줄의 «다시» 를 누르세요. **처음부터 할 필요 없습니다.**
→ 그냥 넘겨도 괜찮습니다. 아무 말 안 한 구간은 자동으로 버려지고,
**몇 개 비어도 데이터로 충분히 쓸 수 있습니다.**

**Q. «보내기»가 안 돼요**
→ 인터넷을 확인하고 한 번 더 눌러 주세요. 계속 안 되면 같은 화면의
**«대신 파일로 받기»** 로 받아서 보내 주시면 **똑같습니다.** 그 사람의 3분이 날아가지 않게
그 경로를 항상 남겨 뒀습니다.

**Q. 목소리가 어디로 가나요**
→ 시작 화면의 **동의 항목**에 적어 뒀습니다 — 졸업작품의 호출어 인식 **학습과 심사에만**
쓰고, **공개 저장소·발표자료에 올리지 않으며**, **2026년 12월(심사 종료) 이후 지웁니다.**
저장소는 비공개라 주소를 알아도 남이 들을 수 없습니다. 언제든 말씀하시면 지워 드립니다.
