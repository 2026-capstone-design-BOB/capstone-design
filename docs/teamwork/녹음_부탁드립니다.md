## 1. 보낼 메시지 (복사해서 쓰세요)

> 안녕하세요! 졸업작품으로 **음성으로 컴퓨터를 조작하는 프로그램**을 만들고 있는데,
> *"플루이즈"* 라고 부르면 반응하게 하는 부분을 **실제 사람 목소리로 학습**시켜야 합니다.
> 지금은 제 목소리랑 기계음만 들어가 있어서 **다른 사람이 부르면 잘 못 알아듣습니다.** 🥲
>
> **3분이면 끝납니다.** 설치할 것 없고, 첨부한 파일을 열면 화면에 말할 내용이 떠요.
>
> 1. 첨부한 **`플루이즈_녹음.html`** 파일을 받아서 **더블클릭** (크롬 권장)
> 2. 이름(별명도 됩니다) 적고 **마이크 허용**
> 3. 화면에 뜨는 대로 말하기 — **더듬거나 틀려도 그 항목만 다시** 하면 됩니다 (처음부터 안 해요)
> 4. 끝나면 **파일 2개**가 다운로드됩니다 → **둘 다** 저한테 보내 주세요
>
> 🔒 녹음은 **그쪽 브라우저 안에서만** 처리되고 어디로도 자동 전송되지 않습니다.
> 파일을 직접 받아서 직접 보내 주시는 방식이라, 보내기 전에 지우셔도 됩니다.
>
> 💡 **조용한 방이면 제일 좋고**, 여유 되시면 **거리를 바꿔서 한 번 더** 해 주시면 큰 도움이 됩니다.

## 3. 받은 파일은 어떻게 하나 (변소윤)

받은 `.wav` + `.json` 쌍을 **`data/wakeword_raw/`** 에 그대로 넣습니다. 이름은 안 바꿔도 됩니다.

```bash
conda activate pluiz
python scripts/ingest_wakeword.py --list      # 누가 몇 명 보냈는지
python scripts/ingest_wakeword.py --holdout 4 # 미학습 화자 4명을 떼고 모은다
```

> 🔒 **`data/` 는 git에 안 올라갑니다**(2026-09-16에 `.gitignore`에 넣었습니다).
> 용량 때문만이 아니라 **사람들 목소리**이기 때문입니다 —
> 동의받은 범위는 «졸업작품 학습»이지 «공개 저장소 게시»가 아닙니다.

## 4. 왜 «플루이즈»만 녹음하지 않는가 — 설명을 요구받으면

녹음이 세 부분입니다. 대부분 *"왜 딴 말도 시켜요?"* 라고 물어봅니다.

| | 무엇 | 왜 |
|---|---|---|
| ① | «플루이즈» 20번 (톤·속도·크기를 바꿔서) | 한 가지 톤만 배우면 **그 톤에만** 반응합니다 |
| ② | *"블루투스 어디서 켜"* 같은 **비슷하지만 다른 말** 10개 | 🚨 **아래 참조 — 여기가 핵심입니다** |
| ③ | **주제를 하나 띄워 주고** 15초씩 3번 | 전시회 부스 앞 잡담이 이 분포입니다.<br>*"아무 말이나 하세요"* 는 사람을 얼어붙게 만들어서 **대답할 수 있는 질문**을 띄웁니다 |

### 🚨 ②가 없으면 «아무 말에나 깨어나는» 모델이 됩니다

**2026-09-09에 실제로 겪었습니다.** 실제 녹음을 **양성으로만** 넣고 학습했더니
검증 성적은 멀쩡한데(감지 93.6% · 오탐 2.35%) **실기에서 아무 말에나 깨어났습니다.**

원인은 임계값이 아니라 **데이터 구성**이었습니다. 학습셋에서 «진짜 마이크 소리»가
전부 양성이면, 모델은 단어를 배울 이유가 없습니다 —
**«기계음이냐 진짜 마이크냐»만 구분해도 만점**이기 때문입니다.

그래서 **같은 마이크로 «플루이즈가 아닌 말»** 을 받아야 그 지름길이 막힙니다.

> 📌 *"블루투스 어디서 켜"* 가 목록에 있는 건 **시연 대본 5장면이라서**입니다.
> 발음이 가깝고 **우리가 직접 말할 문장**이라, 빠지면 시연 중 자기 말에 깨어납니다.

## 5. 자주 나오는 질문

**Q. 마이크가 안 켜져요**
→ 크롬으로 열어 주세요. 브라우저가 물어보는 마이크 권한을 «허용» 해야 합니다.
파일을 더블클릭해서 열었을 때 안 되면, 파일을 **크롬 창에 끌어다 놓으면** 됩니다.

**Q. 중간에 틀렸어요 / 기침했어요 / 더듬었어요**
→ **그 항목만 다시 하면 됩니다.** 화면 아래 «↺ 방금 것 다시» 를 누르거나,
끝나고 나오는 목록에서 해당 줄의 «다시» 를 누르세요. **처음부터 할 필요 없습니다.**
→ 그냥 넘겨도 괜찮습니다. 아무 말 안 한 구간은 자동으로 버려지고,
**몇 개 비어도 데이터로 충분히 쓸 수 있습니다.**

**Q. 파일이 하나만 받아졌어요**
→ 브라우저가 «여러 파일 다운로드»를 막았을 수 있습니다. 허용하거나,
「파일 받기」를 한 번 더 눌러 주세요. **`.wav` 와 `.json` 둘 다** 필요합니다.

**Q. 목소리가 어디로 가나요**
→ 시작 화면의 **동의 항목**에 적어 뒀습니다 — 졸업작품의 호출어 인식 **학습과 심사에만**
쓰고, **공개 저장소·발표자료에 올리지 않으며**, **2026년 12월(심사 종료) 이후 지웁니다.**
언제든 말씀하시면 지워 드립니다.

**Q. 나중에 지워 주나요**
→ 네. 졸업작품 학습·심사가 끝나면 지웁니다. 공개 저장소에는 올라가지 않습니다.
