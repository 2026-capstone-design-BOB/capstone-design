## 2. 저장소 받기 — 둘 중 하나

### 방법 A. GitHub Desktop (권장 — 나중에 갱신이 편합니다)

1. GitHub Desktop 설치 후 실행
2. `File` → `Clone repository` → `URL` 탭
3. 아래 주소를 붙여넣기:
   ```
   https://github.com/2026-capstone-design-BOB/capstone-design
   ```
4. 저장할 폴더를 고르고 `Clone`
5. 🚨 **브랜치를 바꿉니다** — 위쪽 `Current branch` 를 눌러
   **`feature/byeonsoyun`** 을 선택
   > 변소윤이 *"main에 합쳤다"* 고 했으면 이 단계는 건너뜁니다.

### 방법 B. ZIP 내려받기 (가장 간단 · 설치 불필요)

1. https://github.com/2026-capstone-design-BOB/capstone-design 접속
2. 왼쪽 위 브랜치 버튼(`main`)을 눌러 **`feature/byeonsoyun`** 선택
3. 초록색 `Code` 버튼 → `Download ZIP`
4. 압축 풀기

> ⚠️ ZIP은 **받은 시점의 사진**입니다. 내용이 바뀌면 다시 받아야 합니다.

받은 폴더 안에 **`docs/teamwork/` 폴더가 있으면 성공**입니다.

```

```

**`docs/teamwork/` 가 없다면** 브랜치가 잘못된 것입니다. 2번으로 돌아가세요.

## 5. Claude에게 시키는 법

1. 받은 폴더 전체(또는 `docs` 폴더)를 Claude에 올립니다
2. 아래를 복사해서 입력합니다 — **과제 번호만 바꾸면 됩니다**

```
docs/teamwork/과제_01_전시회포스터.md 를 읽고 그대로 진행해 줘.

규칙:
- 프로젝트 내용은 docs/ 폴더 안에서만 찾을 것
- 모르는 건 지어내지 말고 "⬜ 확인 필요: (뭐가 궁금한지)" 로 표시할 것
- 조사 내용에는 반드시 출처 URL을 달 것
- docs/ 폴더 밖의 파일은 절대 수정하지 말 것
```

3. 결과가 나오면 **과제 문서 맨 아래 「✅ 검수 기준」을 직접 하나씩 확인**합니다

> ⚠️ **AI는 모르는 것도 그럴듯하게 써냅니다.** 검수가 당신의 핵심 역할입니다.

## 6. 만든 결과물은 어떻게 전달하나

| 결과물 | 전달 방법 |
|---|---|
| **포스터(.pptx)** · **소개글(.hwp)** | 변소윤에게 **파일로 직접 전달** (카톡·드라이브) |
| **조사 결과·정리 문서(.md)** | 같은 방법. 변소윤이 저장소에 올립니다 |
| e-campus 제출 | ⬜ 팀에서 누가 제출할지 정하기 |

> 💡 직접 저장소에 올리고 싶으면 변소윤에게 **협업자 초대**를 요청하세요.
> 다만 **초대 전에는 올릴 수 없습니다**(읽기만 가능).
