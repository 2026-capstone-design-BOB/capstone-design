## 무엇을 하나

`docs/documentations/작업본/D04_프로덕트백로그.md` 의 **§2.2 사용자 스토리** 표를 채웁니다.

같은 문서 **§2.1에 에픽이 31개(E-01 ~ E-31)** 이미 정리돼 있습니다.
**에픽 하나당 사용자 스토리를 1~3개씩** 만들면 됩니다.

### 사용자 스토리 형식 (이 문장 틀을 지킵니다)

```
사용자는 [왜] 를 위하여 [무엇을] 한다.
```

예시 (이미 문서에 들어 있는 것들):
- `사용자는 손을 쓰지 않고 시스템을 부르기 위하여 "플루이즈"라고 말한다`
- `사용자는 실수로 지우는 것을 막기 위하여 승인 질문에 "응" 또는 "아니"로 답한다`

### 채워야 할 표

| 에픽ID | 에픽명 | US_ID | 사용자 스토리 | 추정작업량 | 우선순위 | 참고 |
|---|---|---|---|---|---|---|

- **US_ID** : `US-01` 부터 순서대로 이어서 붙입니다 (이미 US-08까지 있으니 **US-09부터**)
- **추정작업량** : 1(반나절) · 3(하루) · 5(이틀) · 8(일주일) 중 하나
- **우선순위** : 상 / 중 / 하
- **참고** : 어디서 가져왔는지 **반드시** 적습니다 (예: `BL-24`, `MANUAL_TESTS T-05`)
