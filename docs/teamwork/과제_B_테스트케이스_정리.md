## 채워야 할 표

에픽(E-01 ~ E-31) **그룹별로 표를 따로** 만듭니다.

| Test ID | 테스트 항목 | 입력 데이터/시나리오 | 출력 데이터 |
|---|---|---|---|
| STC-E11-001 | E-11 파일 삭제 정상 | "a.txt 지워줘" → 승인 질문에 "응" | a.txt가 휴지통으로 이동하고, 이동했다고 응답한다 |

- **Test ID 규칙** : `STC-{에픽번호}-{일련번호}` → `STC-E11-001`, `STC-E11-002` ...
- **입력/출력은 «실제 값»으로** 씁니다. *"파일을 지운다"* (X) → *"a.txt 지워줘"* (O)
- **에픽마다 비정상 경우를 최소 1개** 넣습니다 (없는 파일 · 거부 · 실패)
