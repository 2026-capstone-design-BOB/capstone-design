## 6. 🚨 지켜야 할 규칙 4가지

### ① `docs/` 폴더 밖의 파일을 수정하지 않습니다
`services/` · `core/` · `tools/` · `electron-ui/` 는 **프로그램 코드**입니다.
한 글자만 바뀌어도 프로그램이 멈춥니다. **여는 건 괜찮고, 저장하지 마세요.**

### ② 숫자를 지어내지 않습니다
*"응답 속도 3초"* 같은 문장은 **측정한 사람만** 쓸 수 있습니다.
필요한 숫자는 [01_프로젝트_소개.md](01_프로젝트_소개.md) 에 정리해 뒀지만,
**포스터·발표에 넣기 전에 개발자에게 한 번 더 확인**하세요.

> 이 팀에는 *"못 잰 것을 0이라고 쓰지 않는다"* 는 규칙이 있습니다.
> 틀린 숫자가 발표에 올라가면 질의응답에서 바로 무너집니다.

### ③ 출처를 답니다
조사한 내용에는 **URL**, 프로젝트 내용에는 **어느 문서에서 가져왔는지**를 적습니다.

### ④ 모르면 비워 두고 표시합니다
`⬜ 확인 필요: (무엇이 궁금한지)` 라고 적으세요.
**추측으로 채운 칸이 제일 위험합니다.** 비어 있으면 누가 봐도 보이지만,
그럴듯하게 채워져 있으면 아무도 안 봅니다.

> ⚠️ **AI는 모르는 것도 그럴듯하게 써냅니다.** 이 규칙은 AI에게도 똑같이 적용하세요.
