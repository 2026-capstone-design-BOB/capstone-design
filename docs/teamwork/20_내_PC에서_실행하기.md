## 0. 왜 이걸 먼저 하나

지금까지 오다영은 **프로그램을 한 번도 못 본 채로** 포스터·소개글을 쓰고 있었습니다.
그래서 이런 것들이 전부 변소윤을 거쳐야 했습니다.

| 지금 막혀 있는 것 | 실행이 되면 |
|---|---|
| 🔴 **포스터에 넣을 실행 화면 캡처** — [00_시작하기 §3-1](00_시작하기.md)에 *"개발자만 만들 수 있습니다"* 라고 적혀 있습니다 | **직접 찍습니다.** 원하는 장면을 원하는 각도로 |
| «이 기능이 실제로 되는 건가» 확인 | 직접 시켜 봅니다 |
| 실기 테스트 20여 건이 전부 변소윤 몫 | **나눠서 맡을 수 있습니다** |
| 웨이크워드(호출어) 관련 작업을 못 나눔 | 녹음·확인 작업을 맡길 수 있습니다 |

> 🔑 **작업을 나누려면 이게 선행입니다.** 그래서 다른 배정보다 이걸 먼저 합니다.
> 구체적인 분배는 이게 끝난 뒤에 정합니다.

## 1. 🚨 시작 전에 — 두 가지만

### ① 코드를 고치는 게 아닙니다

`core/` · `services/` · `tools/` · `electron-ui/` 는 **여는 건 괜찮고 저장하지 마세요.**
[README §6 규칙 ①](README.md)이 그대로 적용됩니다.

### ② 키는 **본인 것**을 씁니다

변소윤의 키를 받아서 쓰지 않습니다. 애초에 받을 수도 없습니다 —
`.env`(키가 든 파일)와 구글 자격증명은 **저장소에 올라가지 않습니다**(`.gitignore`).
공개 저장소라 올리면 즉시 폐기해야 하는 종류의 파일입니다.

**§4에 본인이 발급받아야 할 것 목록이 있습니다.** 거기가 이 문서의 핵심입니다.

## 3. 소스 받기 — 🚨 **브랜치를 확인하세요**

최신 작업은 아래 브랜치에 있습니다. **`main` 이 아닙니다.**

```
dev/post-demo
```

- **GitHub Desktop**: `Current branch` → `dev/post-demo` 선택 → `Fetch origin` → `Pull`
- **명령어**: `git clone https://github.com/2026-capstone-design-BOB/capstone-design.git`
  → 폴더 안에서 `git checkout dev/post-demo`

### 제대로 받았는지 확인

받은 폴더에 **`launch.bat` 파일이 보이면** 성공입니다.
`docs/teamwork/` 만 있고 `launch.bat` 이 없으면 브랜치가 잘못된 것입니다.

> ⏸️ **변소윤 확인 필요** — 이 문서를 쓰는 시점에 아직 서버에 안 올라간 작업이 있습니다.
> **"올렸다"는 연락을 받은 뒤에** 내려받으세요. 그 전에 받으면 웨이크워드가 옛 모델입니다.

## 5. 설치 — 명령 다섯 줄

`cmd`(명령 프롬프트)를 열고, **받은 폴더 안에서** 차례대로 칩니다.

```bat
conda create -n pluiz python=3.11 -y
conda activate pluiz
pip install -r requirements.lock.txt
python -m playwright install chromium
copy .env.example .env
```

| 줄 | 무엇 | 걸리는 시간 |
|---|---|---|
| 1~2 | 이 프로젝트 전용 파이썬 방을 만들고 들어갑니다 | 1분 |
| 3 | 필요한 라이브러리 60여 개 설치 | **10~20분** |
| 4 | 웹페이지 읽기용 브라우저 | 3분 |
| 5 | 설정 파일 만들기 | 즉시 |

> 🚨 **`conda activate pluiz` 를 매번 해야 합니다.** 새 창을 열면 풀립니다.
> 이걸 빼먹으면 `ModuleNotFoundError` 가 납니다 — 이 프로젝트에서 제일 흔한 실수입니다.

> ⚠️ 3번에서 오류가 나면 `pip install -r requirements.txt` 로 한 번 더 해 보세요.
> 그래도 안 되면 **오류 메시지 전체를 캡처해서** 변소윤에게 보내세요.

### 5-1. 키 넣기

메모장으로 `.env` 파일을 열고 이 줄을 찾아 **`=` 뒤에 붙여넣습니다.**

```
GEMINI_API_KEY=
```

따옴표는 넣지 않습니다. 저장하고 닫습니다.

> 💡 **프로그램을 먼저 띄운 뒤 설정 화면에서 넣어도 됩니다.** 편한 쪽으로 하세요.

## 6. 실행

받은 폴더에서 **`launch.bat` 을 더블클릭**합니다.
검은 창 두 개가 뜨고(서버·화면), 잠시 뒤 Pluiz 창이 나타납니다.

> 끄는 법: **검은 창 두 개를 닫습니다.**

### 안 되면 — 하나씩 나눠서

```bat
conda activate pluiz
python main.py
```

이 창에 오류가 찍히면 그게 원인입니다. 화면에 `http://127.0.0.1:8765` 가 보이면 서버는 정상입니다.

## 7. ✅ 제대로 됐는지 — 세 가지만 해 보세요

| | 해 볼 것 | 되면 |
|---|---|---|
| **①** | 창이 떴다 | 화면·설치 OK |
| **②** | 글자로 **"메모장 열어줘"** 입력 | **메모장이 실제로 열립니다.** 여기까지 되면 키·서버 전부 OK |
| **③** | 마이크에 대고 **"플루이즈"** 라고 부른다 | 창이 깨어납니다. ⚠️ 잘 안 깨어나는 게 지금 알려진 문제입니다 — **안 깨어나도 ①②가 되면 성공입니다** |

**③까지 확인되면 변소윤에게 알려 주세요.** 거기서부터 작업을 나눕니다.

## 8. 안 될 때

| 증상 | 원인 · 해결 |
|---|---|
| `ModuleNotFoundError` | `conda activate pluiz` 를 안 한 것입니다. 새 창마다 다시 쳐야 합니다 |
| 대답을 못 한다 / «키가 없다» | `.env` 의 `GEMINI_API_KEY` 가 비었거나 따옴표가 들어간 것입니다 |
| 글자가 깨진다 | `set PYTHONIOENCODING=utf-8` 을 먼저 친 뒤 실행하세요 |
| `포트 8765 사용 중` | 서버가 이미 떠 있습니다. 검은 창을 다 닫고 다시 하세요 |
| **"플루이즈"에 안 깨어난다** | 알려진 문제입니다(10번 중 1~2번 놓칩니다). 계속 안 되면 `.env` 에<br>`PLUIZ_PYTHON=C:\Users\이름\miniconda3\envs\pluiz\python.exe` 한 줄을 추가 |
| 마이크가 안 잡힌다 | Windows 설정 → 개인정보 → 마이크 → **데스크톱 앱 허용** |
| 그 외 | **오류 메시지 전체를 캡처**해서 변소윤에게. 어느 단계(§ 번호)에서 막혔는지 같이 |

> 🚨 **30분 이상 혼자 붙들지 마세요.** 환경 문제는 캡처 한 장이면 대부분 바로 풀립니다.
