## 1. 띄우기

폴더에서 **`launch.bat` 을 더블클릭**합니다. 검은 창 두 개(서버·화면)가 뜨고
잠시 뒤 알약 모양 창이 나타납니다.

| 하고 싶은 것 | 어떻게 |
|---|---|
| 말로 시키기 | 알약을 **더블클릭** → 말하기 |
| 글로 시키기 | 알약을 **펼치고** 아래 칸에 입력 |
| 불러서 깨우기 | **"플루이즈"** 라고 부르기 (가끔 못 듣습니다 — 알려진 문제) |
| 끄기 | 검은 창 두 개 닫기 |

## 2. 무엇을 시킬 수 있나

전체 목록은 [`docs/전체_기능_설명.html`](../전체_기능_설명.html) 에 있습니다
(**코드에서 자동으로 만들어지는 문서**라 항상 최신입니다).
브라우저로 열면 됩니다. 아래는 맛보기입니다.

| 해 볼 말 | 무슨 일이 일어나나 |
|---|---|
| *"메모장 열어줘"* | 메모장이 열립니다. **AI 를 안 부르고도** 되는 명령입니다 |
| *"오늘 날씨 어때"* | 날씨를 말로 알려 줍니다 |
| *"볼륨 30으로 해줘"* | 소리 크기를 바꿉니다 |
| *"바탕화면에서 발표 파일 찾아줘"* | 파일을 찾아 줍니다 |
| *"1분 뒤에 물 마시라고 알려줘"* | **1분 뒤에 먼저 말을 겁니다** |
| *"오늘 일정 알려줘"* | 구글 일정을 읽습니다 (연결 필요) |
| *"내일 3시에 회의 일정 만들어줘"* | 일정을 만듭니다 |
| *"지금까지 뭐 했지?"* | 이번 대화에서 한 일을 정리해 줍니다 |
| *"이 파일 지워줘"* | 🚨 **먼저 물어봅니다.** 되돌릴 수 없는 일은 승인을 받습니다 |

> 🔑 **승인을 물어보는 것은 고장이 아닙니다.** 지우기·강제 종료처럼 되돌릴 수
> 없는 일에만 묻도록 일부러 만든 것입니다. 거기서 *"응"* 이라고 답하면 진행합니다.

## 3. 🚩 이상하면 **그 자리에서** 신고

Pluiz 답변에 마우스를 올리면 **🚩** 가 나타납니다. 누르면 신고 화면이 열립니다.

```
🤖 메모장을 열었어요          🚩
```

| 앱이 **알아서** 채우는 것 | 당신이 하는 것 |
|---|---|
| 내가 뭐라고 말했는지 (토씨 그대로) | 네 가지 중 고르기 |
| Pluiz 가 뭐라고 답했는지 | *"뭘 기대했나요?"* 한 줄 (**비워도 됩니다**) |
| 시각 · 그때 로그 | 누가 · 어디서 (고르기만) |

| 표시 | 언제 |
|---|---|
| `⬜` | 안 되거나 이상하다 |
| `😕` | **되긴 되는데 답답하다** (느리다 · 말투가 어색하다 · 왜 묻는지 모르겠다) |
| `💡` | 이런 것도 되면 좋겠다 |
| `👍` | **잘 됐다** |

> ### 🔑 `😕` 와 `👍` 를 꼭 눌러 주세요
>
> `😕` 는 *"되긴 되니까"* 하고 제일 안 적히는데, 교수님이 보시는
> **«실사용성»** 이 정확히 거기입니다.
> `👍` 는 포스터·발표에 **그대로 쓸 재료**가 됩니다.

🚨 **«왜 그런 것 같은지»는 적지 마세요.** 적는 칸도 없습니다. 추측이 적혀 있으면
개발자가 그걸 먼저 믿고 엉뚱한 데를 팝니다 — 실제로 겪은 일입니다.
**무슨 일이 일어났는지만** 있으면 됩니다. 나머지는 앱이 압니다.

보낸 것은 설정이 돼 있으면 **변소윤에게 바로** 갑니다. 안 돼 있으면 화면이
«전달은 안 됐어요» 라고 말하고 파일 위치를 알려 줍니다 — 그때는 그 파일을 보내세요.

## 4. 안 될 때 — Claude Code 에게 이렇게 물어보세요

Pluiz 폴더에서 Claude Code 를 열고 그대로 말하면 됩니다.

| 상황 | 말할 것 |
|---|---|
| 창이 안 뜬다 / 오류가 났다 | **`로그 보고 방금 무슨 일이 있었는지 알려줘`** |
| 명령이 안 먹는다 | **`14시 32분쯤 메모장 열어줘 했는데 안 됐어. 로그 봐줘`** ← **시각을 같이** |
| 뭐가 되는지 모르겠다 | **`지금 할 수 있는 일 알려줘`** |
| 이 기능이 왜 이러지 | **`승인은 왜 물어보는 거야?`** 처럼 그냥 물어보세요 |

> 🚨 **시각(분까지)을 같이 말해 주세요.** Claude Code 가 `logs/pluiz.log` 에서
> 그 순간을 찾아 **무슨 일이 있었는지 그대로** 봅니다. 시각이 없으면 못 찾습니다.
> 🔑 신고(🚩)는 시각을 **자동으로** 넣어 주니 그쪽이 더 편합니다.

## 5. 알아 두면 좋은 것

| | |
|---|---|
| **아직 완성이 아닙니다** | 안 되는 게 나오는 게 정상입니다. 그걸 찾는 게 작업입니다 |
| **최신으로 두세요** | 거의 매일 바뀝니다. 쓰기 전에 `git pull` → [클로드코드_루틴 §0](클로드코드_루틴.md) |
| **화면이 밖으로 나갈 때가 있습니다** | 「화면 보고 알려줘」 류 명령은 스크린샷이 AI 로 갑니다. **비밀번호·계좌가 떠 있을 때는 시키지 마세요** |
| **인터넷이 없어도** | 자주 쓰는 명령 일부는 됩니다. 전부는 아닙니다 |
| **구글 일정·메일** | 본인 계정으로 따로 연결해야 합니다 → [`docs/구글_연결.md`](../구글_연결.md) |
| **7일마다 구글 연결이 끊깁니다** | 알려진 제약입니다. 다시 로그인하면 됩니다 |
| **코드를 고치지 마세요** | 여는 건 괜찮고 저장하지 않습니다 |

## 6. 써 보고 나서 변소윤에게 알려 줄 것

- 🚩 로 보낸 것이 **몇 건인지** (보냈으면 그걸로 충분합니다)
- 🚩 를 못 쓴 상황이 있었다면 **그게 뭐였는지** (예: 창이 아예 안 떴다)
- `👍` 로 적은 것 중 **포스터에 쓸 만한 것**
