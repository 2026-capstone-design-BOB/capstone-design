## 포스터에 들어갈 내용

전시회에서 **지나가는 사람이 3초 안에 «이게 뭔지» 알아야** 합니다.

| 영역 | 내용 | 재료 위치 |
|---|---|---|
| 제목 | **Pluiz** — 한국어 음성 명령으로 Windows PC를 제어하는 AI 에이전트 | 이 문서 |
| 한 줄 소개 | "말하면 컴퓨터가 대신 합니다" 수준의 쉬운 한 문장 | 직접 작성 |
| 시스템 구성도 | 그림 1장 | ⚠️ **저장소에 없습니다 — 변소윤에게 요청하세요.** 아래 참고 |
| 주요 기능 | 4~6개만 고릅니다. **전부 넣으면 아무것도 안 읽힙니다** | [D03 §2.3](../documentations/작업본/D03_소프트웨어기능아키텍처.md) 13개 중 선별 |
| 실행 화면 | 스크린샷 2~3장 | ⬜ **개발자에게 요청** — 아직 없습니다 |
| 차별점 | 3가지 | 아래 |
| 팀 정보 | 학과 · 팀명 · 팀원 · 지도교수 | ⬜ 확인 필요 |

## 차별점 3가지 (이대로 쓰면 됩니다)

1. **인터넷 없이도 동작합니다** — 자주 쓰는 명령은 학습되어 서버 없이 실행됩니다.
2. **위험한 동작은 반드시 물어봅니다** — 파일 삭제 같은 되돌릴 수 없는 일은 승인 후에만 실행합니다.
3. **화면을 보고 길을 안내합니다** — "블루투스 어디서 켜?" 에 설정을 **열어서 위치를 짚어** 줍니다.

> ⚠️ **속도 수치(몇 초 → 몇 초)는 개발자에게 확인한 뒤에 넣으세요.** 지금 문서의 숫자는 중간 측정값이라
> 최종값과 다를 수 있습니다.

## ⚠️ 구성도 그림 문제

기존 구성도 그림은 **저장소에 올라가 있지 않고**(발표 산출물이라 로컬 보관),
게다가 **2026년 9월 1일 기준**이라 현재 구조와 다릅니다.
두 가지 방법 중 하나:

- **(권장)** 개발자에게 «현재 구조 한 장» 을 받아서 새로 그린다
- 기존 그림을 쓰되, **무엇이 빠졌는지 개발자에게 확인**받고 쓴다
