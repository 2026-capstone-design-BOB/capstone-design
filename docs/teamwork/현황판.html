3글을 쓰는 순서

9/22 피드백을 그대로 절차로 바꾼 것입니다. 기능부터 쓰면 “그래서 뭐?”가 됩니다.

  1. ① 문제 사용자가 실제로 겪는 불편을 먼저 씁니다. 기능 이름을 아직 꺼내지 않습니다.
  2. ② 왜 어려운가 어필의 핵심입니다. 어려운 줄 모르면 대단한 줄도 모릅니다. “그냥 하면 왜 안 되는지”를 한두 문장으로.
  3. ③ 어떻게 풀었나 우리가 한 선택. 남들과 다른 점이 여기서 나옵니다.
  4. ④ 숫자 + 단서 숫자가 없으면 주장이고, 단서가 없으면 과장입니다. 둘 다 씁니다.

“Windows 음성 액세스보다 낫습니다” 재지 않았고 겨냥하는 것이 다릅니다. “다른 물건입니다”라고 말합니다
