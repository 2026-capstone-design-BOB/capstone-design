# 환경 세팅 따라하기 — 처음부터 끝까지 약 30분

> 변소윤이 옆에서 같이 보면서 진행하는 용도입니다.
> 자세한 배경과 «왜 하는가»는 [20_내_PC에서_실행하기.md](20_내_PC에서_실행하기.md) 에 있습니다.
> 이 문서는 **칠 명령과 확인할 것만** 순서대로 적은 것입니다.

**전제**: Conda · Node.js · Git 이 이미 깔려 있습니다.
**준비물**: Gemini API 키 (<https://aistudio.google.com/apikey> · 3분)

---

## 0. Anaconda Prompt 열기

시작 메뉴에서 **"Anaconda Prompt"** 를 검색해서 엽니다.

> 🚨 일반 `cmd` · PowerShell · Git Bash 는 쓰지 마세요.
> 거기선 `conda activate` 가 조용히 실패하는데, **실패해도 다음 명령이 그냥 돌아서**
> 패키지가 엉뚱한 파이썬에 깔립니다. 한참 뒤에 서버가 죽고 원인을 찾기 어렵습니다.

---

## 1. 저장소 받기 (2분)

```bat
cd %USERPROFILE%\Documents
git clone https://github.com/2026-capstone-design-BOB/capstone-design.git
cd capstone-design
git checkout dev/post-demo
git branch --show-current
```

### ✅ 확인

마지막 줄이 **`dev/post-demo`** 라고 나와야 합니다.

`main` 이 나오면 안 됩니다. `main` 은 1학기 데모 시점이라 구글 연결도 일정 수정도
없는 옛날 코드입니다. 폴더에 `launch.bat` 이 보이는지도 같이 보세요.

---

## 2. 가상환경 만들기 (3분) — 🚨 **여기가 제일 중요합니다**

```bat
conda create -n pluiz python=3.11 -y
conda activate pluiz
python -c "import sys; print(sys.executable)"
```

### ✅ 확인

마지막 줄 경로에 **`envs\pluiz`** 가 들어 있어야 합니다.

```
C:\Users\이름\anaconda3\envs\pluiz\python.exe     ← 정상
C:\Users\이름\anaconda3\python.exe                ← 🚨 여기서 멈추세요
```

두 번째가 나오면 `conda activate` 가 안 먹은 것입니다.
**이 상태로 다음 단계를 진행하면 전부 헛수고가 됩니다.**
프롬프트 왼쪽에 `(pluiz)` 가 떠 있는지도 같이 보세요.

> 🚨 **새 창을 열면 풀립니다.** 창을 새로 열 때마다 `conda activate pluiz` 를 다시 칩니다.
> 이 프로젝트에서 제일 흔한 실수입니다.

## 3. 파이썬 패키지 설치 (5~20분)

```bat
pip install -r requirements.lock.txt
```

> 📌 `requirements.txt` 가 **아니라** `requirements.lock.txt` 입니다.
> 앞엣것은 «왜 이 패키지가 필요한가»를 적은 설명 문서라 하한(`>=`)만 있습니다.
> 그걸 깔면 설치할 때마다 최신이 들어와 **코드를 안 고쳐도 어느 날 깨집니다.**

> ⏳ 여기부터 5번까지가 오래 걸립니다. 기다리는 동안 **9번(구글 연결)** 을
> 미리 해 두면 시간이 겹칩니다.

## 6. 설정 파일 + API 키 (2분)

```bat
copy .env.example .env
notepad .env
```

메모장이 열리면 `GEMINI_API_KEY=` 를 찾아 **등호 뒤에 키를 붙여넣고** 저장합니다.

```
GEMINI_API_KEY=AIza...        ← 따옴표 없이 값만
```

> 💰 무료 한도가 있습니다. 개인 테스트 수준이면 돈이 안 나갑니다
> (한 달 실사용 측정에서 $0.13 이었습니다).
> 🔒 이 키는 비밀번호입니다. 카톡·메일로 남에게 보내지 마세요.

## 7. 중간 점검 (4초) — 🔑 **키 없이도 됩니다**

```bat
set PYTHONIOENCODING=utf-8
python tests\test_dependencies.py
```

### ✅ 기대

```
결과: 40/40 통과
```

빠진 패키지가 있으면 **이름을 알려줍니다.**

> 이 검사가 따로 있는 이유 — 도구들이 패키지가 없으면 예외를 삼키고 조용히
> 폴백합니다. 그래서 **기능이 망가졌는데 테스트는 통과하는** 일이 실제로 있었습니다.

## 9. 실제로 띄우기 (1분)

```bat
launch.bat
```

검은 창 두 개(서버 · 화면)가 뜨고, 잠시 뒤 알약 모양 UI 가 나타납니다.

| | 해 볼 것 | 되면 |
|---|---|---|
| ① | 창이 떴다 | 화면 · 설치 OK |
| ② | 펼쳐서 글자로 **"메모장 열어줘"** | 메모장이 실제로 열립니다. 서버까지 OK (이건 키 없이도 됩니다) |
| ③ | **"오늘 날씨 어때"** | 대답이 오면 **LLM 키까지 정상** |
| ④ | 마이크에 대고 **"플루이즈"** | 창이 깨어납니다. ⚠️ 가끔 놓치는 게 알려진 문제라 **안 돼도 ①~③ 이 되면 성공입니다** |

끄는 법: **검은 창 두 개를 닫습니다.**

### 안 되면 — 나눠서 봅니다

```bat
conda activate pluiz
python main.py
```

이 창에 찍히는 오류가 원인입니다. `http://127.0.0.1:8765` 가 보이면 서버는 정상입니다.

## 10. 구글 연결 (15분 · 나중에 해도 됩니다)

일정 · 메일을 쓸 거면 [docs/구글_연결.md](../구글_연결.md) 를 그대로 따라합니다.
구글 클라우드 콘솔에서 프로젝트를 만들고, 받은 JSON 을 **저장소 루트에
`calendar_credentials.json`** 이름으로 둡니다.

그 뒤 UI 에서 *"오늘 일정 알려줘"* 라고 하면 **브라우저가 알아서 뜹니다.**
거기서 한 번 로그인하면 끝입니다.

> 🔒 **변소윤의 `calendar_token.json` 을 복사해 쓰지 않습니다.**
> 그 파일은 그 계정의 일정과 메일을 읽는 열쇠입니다. 본인 계정으로 따로 합니다.
> ⚠️ 동의 화면이 «테스트» 상태라 **7일마다 연결이 끊깁니다.**
> 끊기면 `python scripts/connect_google.py` 를 한 번 더 돌립니다.

## 막히면

| 증상 | 원인 · 할 것 |
|---|---|
| `ModuleNotFoundError: langgraph` | **2번을 다시 하세요.** 다른 파이썬에 깔린 것입니다 |
| 글자가 `???` 로 깨진다 | `set PYTHONIOENCODING=utf-8` 을 먼저 칩니다 |
| 테스트가 엉뚱하게 실패한다 | Git Bash 에서 돌린 경우입니다. **Anaconda Prompt** 로 |
| 대답을 못 한다 / «키가 없다» | `.env` 의 `GEMINI_API_KEY` 가 비었거나 따옴표가 들어간 것 |
| `포트 8765 사용 중` | 서버가 이미 떠 있습니다. 검은 창을 다 닫고 다시 |
| UI 는 뜨는데 명령이 안 먹는다 | 서버 창이 살아 있는지 · `logs\pluiz.log` |
| 일정이 계속 «로그인이 안 됐어요» | 구글 콘솔 **테스트 사용자**에 본인 계정이 있는지 |
| 마이크가 안 잡힌다 | Windows 설정 → 개인정보 → 마이크 → **데스크톱 앱 허용** |
| 그 외 | **오류 메시지 전체를 캡처**해서 변소윤에게. 몇 번 단계인지도 같이 |

> 🚨 **30분 이상 혼자 붙들지 마세요.** 환경 문제는 캡처 한 장이면 대부분 바로 풀립니다.

이상한 점이 보이면 고치지 말고 적어서 전달하세요 → [사용_피드백.md](사용_피드백.md)
