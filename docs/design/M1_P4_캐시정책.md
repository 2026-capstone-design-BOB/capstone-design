# Pluiz v2 — P4 커맨드 캐시 정책 (Cache Policy)

> **작성일**: 2026-08-14
> **상태**: 확정 (Agreed)
> **목적**: 오프라인 실행 + "사용할수록 맞춤형" 차별화. 단, **오염 방지·롤백·확장 용이**를
> 최우선으로 하는 규칙을 고정한다.

---

## 0. 설계 원칙
- **비파괴적 확장**: 동적 학습은 "표현 → 기존 인텐트" 추가만. 기존/시드 불변.
- **명확한 분리**: 시드(seed) ↔ 동적(dynamic)을 `source`로 구분 → 동적만 한 번에 초기화 가능.
- **오염 원천 차단**: 파라미터(자유 텍스트/숫자)는 절대 학습하지 않음.
- **교체 용이**: 매칭은 Stage로 분리 → 후에 임베딩(A)으로 Stage-2만 교체.

## 1. 무엇을 캐싱하나 (자격)
- **시드**: 기본 제어 명령(고정, 삭제 불가).
- **동적 학습 대상 = 화이트리스트 도구만** (파라미터 없음 / 고정어휘):
  `open_app`·`close_app`(알려진 앱), `maximize_window`·`minimize_window`·`show_desktop`,
  `volume_up`·`volume_down`(기본량), `mute_toggle`, `brightness_up`·`brightness_down`,
  `take_screenshot`, `get_battery_status`·`get_current_time`·`get_running_apps`,
  `open_recent_file`.
- **절대 학습 안 함**: 자유 파라미터 명령(폴더명·검색어·`set_volume` 숫자·`type_text`·
  `create_file`·`write_excel`·`youtube_search`·`map_search`), 위험 명령(삭제 등 HITL 대상),
  대화형·정보조회, 보안 차단 입력, 실패(도구 오류) 명령.

## 2. 저장 구조 (CacheEntry)
```
pattern          : 정규화된 사용자 표현(키)
tool_calls       : 캐노니컬 도구 호출(파라미터 없는/고정어휘)
response_template: 응답 문구
hit_count        : 사용 횟수
is_seed          : 시드 여부(삭제 보호)
source           : "seed" | "dynamic"        # 신규
learned_at       : 학습 시각(ISO)             # 신규
last_used        : 마지막 사용 시각(ISO)       # 신규
```
> 신규 필드는 기본값 있음 → 기존 JSON 하위호환.

## 3. 탐색 로직 (find, Stage)
1. **Stage 1 — Intent**: (entity, action) 추출 → intent_index 직접 조회(정확, 켜줘/꺼줘 구분).
2. **Stage 2 — 의미 유사도**: B(경량: 학습표현·동의어 포함 SequenceMatcher) → 후에 A(임베딩)로 교체.
   임계값 `SIMILARITY_THRESHOLD = 0.80`(settings).
3. 미스 → 라우터 → LLM.

## 4. 학습 트리거 (learn)
- 시점: **LLM이 성공 실행한 직후 1회 즉시**.
- 조건(전부 충족): 실행 도구가 화이트리스트 + 자유 파라미터 없음 + 도구 오류 없음 + 보안 통과.
- 방식: 성공한 tool_calls에서 캐노니컬 인텐트를 도출 → 사용자 표현을 그 인텐트의 새 트리거로 추가.
  (파라미터는 저장하지 않음)
- 중복/모호: 이미 있으면 hit_count·last_used만 갱신. 한 표현이 여러 인텐트면 최근·빈도 우선.

## 5. 용량·정리
- 시드는 카운트 제외(항상 유지).
- 동적 상한 `cache_max_dynamic = 200`(settings). 초과 시 **LRU**(last_used 오래된 동적부터) 제거,
  단 hit_count 높은 항목은 보호.

## 6. 관리 (API, 시드 보호)
- `GET /cache` : 목록/통계 조회(seed·dynamic 구분).
- `DELETE /cache/{pattern}` : 개별 삭제(동적만; 시드 거부).
- `DELETE /cache?scope=dynamic` : **동적 전체 초기화**(오염 롤백 원버튼). seed 유지.
- 손상 시 자동 재시드(시드로 복구).

## 7. 스위치·오프라인·영속성
- `cache_learning = true`(settings) : 동적 학습 on/off 스위치.
- 캐시 히트는 오프라인 O. `cache/command_cache.json`에 저장, `source`로 구분.

## 8. 결정 요약
| # | 결정 | 값 |
|---|---|---|
| D1 | 동적 상한 | 200 (settings) |
| D2 | 정리 | LRU + hit 보호 |
| D3 | 학습 시점 | 1회 성공 즉시 |
| D4 | 관리 | API만(+시드보호), UI 후속 |

## 9. 확장 로드맵
- **P4-B(이번)**: 안전한 동적 학습 + 경량 매칭 + 관리 API.
- **P4-A(후속 선택)**: Stage-2를 로컬 임베딩 유사도로 교체(오프라인 의미매칭 강화).
