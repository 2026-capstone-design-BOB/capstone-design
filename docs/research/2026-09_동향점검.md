## ③ 경쟁 서비스 — 공식 문서 기준선

2026-09-08에 공식 문서를 직접 읽고 정리한 것이다(원문 요약은
[`docs/meetings/2026-09-08_프로젝트_청사진.html`](../meetings/2026-09-08_프로젝트_청사진.html)).
**2회차는 이 표와 diff 한다.**

### Anthropic Computer use

- **상태**: Claude API · Google Cloud에서 **정식 출시(GA)**, AWS Bedrock ·
  Microsoft Foundry에서는 **베타**
- **방식**: 스크린샷을 보고 사람처럼 클릭 · 타이핑
- **문서가 스스로 밝힌 한계**: 드롭다운 · 스크롤바 같은 UI는 마우스로 다루기 까다로움
  (키보드 단축키 권장) · 클릭 정확도 문제의 원인으로 **좌표 스케일 불일치 · 축소로 인한
  작은 글자 손실 · 낮은 해상도**를 명시
- **비용 축**: 스크린샷 **1장당 약 1,000~1,800 토큰**, 한 요청에 20장 초과 시 제한 강화
- **보안**: 프롬프트 인젝션 경고(화면 속 지시가 사용자 지시를 덮어쓸 수 있음),
  **격리 VM/컨테이너 권장** · 자격증명 제공 금지 · 중대한 행동에 사람 승인

### Microsoft Copilot Actions (Windows 11)

- **상태**: **실험적 프리뷰** (Windows Insiders의 Copilot Labs). **기본값 꺼짐** —
  설정 › 시스템 › AI 구성 요소 › 에이전트 도구에서 켬
- **구조**: **에이전트 전용 계정 + 격리된 「에이전트 작업 공간」.** 사용자 데스크톱에
  대한 가시성 제한, 접근 범위는 문서 · 다운로드 · 바탕화면 · 사진 등 알려진 폴더로 한정
- **방식**: "비전과 추론을 써서 사람처럼 클릭 · 타이핑 · 스크롤"

### 이게 우리 자리를 어떻게 정하나

**둘 다 «매 단계 화면을 본다».** Pluiz는 아는 명령을 네이티브 Windows API로 바로 부르므로
그 경로에서 **화면이 한 장도 밖으로 나가지 않고 LLM 호출도 0회**다. 모르는 것만 화면을 본다.

> **⑤가 이 문장의 증거다.** 오늘 심은 계측이 `LLM 0회(캐시) | 토큰 0`을 로그에 남긴다 —
> 지금까지는 **말로만 하던 주장**이었다.

**정직한 약점**(먼저 말한다): 범용성에서 진다(도구 39개가 덮는 범위만). 그리고 우리는
**격리 환경이 아니라 사용자 데스크톱에서 직접** 동작한다 — 그래서 «되돌릴 수 없는 동작에는
사람 승인» · «화면 감시에는 시간 · 횟수 상한»을 **구조로 강제**하는 데 개발 비중을 크게 썼다.

**조치했나** — 없다. 기준선이라 조치할 대상이 없다.
2회차에 볼 것: computer use의 **베타 → GA 전환** 여부, Copilot Actions의 **프리뷰 졸업** 여부.
후자가 정식 출시되면 «Windows 기본 탑재」가 되므로 **차별화 서사를 다시 써야 한다.**
