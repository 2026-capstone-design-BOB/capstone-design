**더 파 보니 틀렸다** — **Agent S3가 사람 수준(약 70%)에 도달했다.**

| | |
|---|---|

> 🔑 **그래서 «둘 다 쥐고 싼 것부터»가 이 지형의 답이다.**

> **«한국어 자연어 + 확실성 + 승인 구조»를 동시에 가진 것이 조사 범위 안에 없다.**

## 6. 🧭 이 조사에서 나온 **개발 이념** (발표용)

> 이 다섯은 **조사에서 귀납된 것**이지 구호가 아니다. 각 줄에 **근거가 붙는다.**

| | 이념 | 근거 |
|---|---|---|
| **1** | **«되면 확실히»를 «아무거나 되게»보다 앞에 둔다** | Windows 한정 벤치마크가 **아직 20%대**다. 범용 화면 조작에 올인하면 **시연에서 깨진다** |
| **2** | **아는 일은 모델을 안 부른다** | 캐시 히트 **22.4%** · **0.09초 vs 9.25초**. 화면도 안 나간다 |
| **3** | **정해진 문법을 외우게 하지 않는다** | 음성 액세스 실측 — *"메모장 열어"* **안 열림.** 이게 LLM을 쓰는 이유 자체다 |
| **4** | **모델이 결정하는 만큼 사람에게 묻는다** | 저쪽은 **사람이 명령을 정의**하니 승인이 필요 없다. **우리는 모델이 판단한다** |
| **5** | **못 한 것은 못 했다고 말한다** | 이 저장소가 **일곱 번** 고친 결함이 «확인 없이 됐다고 말하는 것»이다 |
| **6** | 🆕 **못 하는 일도 막다른 길로 두지 않는다 — 근거를 찾아 «방법»을 알려준다**<br>⚠️ 단, **근거를 못 대면 «모른다»고 한다** | 아래 |

### 🚨 ⑥은 **2026-09-17에 사용자가 지적해 되살린 줄**이다

처음에 나는 ①~⑤만 뽑았다. **경쟁사와 비교해서 나온 축만 봤기 때문**이다.
사용자가 짚었다 — *"도구가 없어서 해주진 못하더라도 **방법이나 해결법을 적절히 제시**해 줄 수 있는
**정보성과 해결력**도 있어야 하지 않아?"*

**맞다. 그리고 그건 이미 우리가 하던 일이다** —
**시연 5장면(*"블루투스 어디서 켜?"*)이 정확히 그것**이고, 대본에 **«프로젝트의 얼굴»** 이라고 적혀 있다.
🚨 **나는 얼굴을 빼놓고 이념을 썼다.**

| 지금 | |
|---|---|
| 재료 | ✅ 웹 검색 · 페이지 읽기 · 본문 긁기 · 날씨 · 화면 이해 · 설정 열기 — **다 있다** |
| 🔴 **없는 것** | **«못 하면 방법을 찾아본다»는 연결.** 지금은 *"죄송해요, 방금 건 처리하지 못했어요"* 로 **끝난다**(`core/graph.py`) |
| 같은 모양 | [BL-56](../BACKLOG.md) — *"지금까지 한 거 뭐 했는지 정리해 줄래"* → «못함». **재료는 있는데 보는 자리가 없다** |

> 🔑 **그리고 이건 차별점으로도 센다.** 음성 액세스는 문법에 없으면 **오류 메시지**로 끝나고,
> Talon도 등록 안 된 명령은 그냥 안 된다.
> **«못 하는 것을 만났을 때 무엇을 하는가»는 조사 범위 안에서 아무도 안 채운 칸이다.**

> 🔑 **발표에서 쓸 한 문장** —
> ***"저희는 시장을 재고 나서 «범용성»이 아니라 «확실성 · 한국어 · 안전 · 그리고 해결력»을 골랐습니다.
> 앞의 셋을 동시에 가진 것이 조사 범위 안에 없었고, 마지막 하나는 아무도 채우지 않았기 때문입니다."***
