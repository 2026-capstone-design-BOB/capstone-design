구성 학습 음성 평가 소크 성격
A 🔵 카페를 쪼갠다 10/01 집 45분 + 카페 앞 20분 카페 뒤 10분 + 대선토론 겹치지 않는다. 카페를 배우고 카페로 잰다

🙋 A 를 추천한다. 쪼개는 건 명령 한 줄이고, B 는 이번 수집의 목적(«남의 말소리를 배우게 한다»)을 못 쓴다.

▶️ 정하면 이 순서로 (준비 10분 + 학습 약 17분)

🚨 순서가 중요하다. add_soak_to_negatives.py 는 기준 풀을 data/wakeword/negative.npy 로 고정해서 읽는다(인자로 못 바꾼다). 그래서 ingest 가 먼저다 — 지금 negative.npy 는 9/28 것이라 녹음자6·변소윤 두 세션이 안 들어 있다.

# ② 학습에 넣을 소크를 **한 파일로** 만든다
#    🔑 add_soak 은 기준이 negative.npy 로 고정이라 **이어 돌릴 수 없다.**
#    여러 소크를 넣으려면 wav 를 먼저 이어 붙인다.

# ③ 음성 풀에 더한다 — ⚠️ --out 을 준다
#    (기본 이름 negative_plus.npy 는 **10/01 것이 이미 있다** — 덮어쓰지 않는다)
python scripts/add_soak_to_negatives.py <학습용 wav> --apply --out data/wakeword/negative_1003.npy

# ④ 학습 (약 17분)
python scripts/train_wakeword.py --jobs 0 --user-neg data/wakeword/negative_1003.npy

# ⑤ 판정 — 🚨 sim_consecutive 로 한다
python scripts/sim_consecutive.py <평가용 wav> --model services/wakeword_model_candidate.npz

4코드를 고치기 전 — 절대 규칙

어기면 바로 깨지는 것들입니다. 배경은 CLAUDE.md 의 각 링크에.

  • 그래프 노드를 async로 바꾸지 말 것
  • `fast_path` 히트를 조기 return으로 "최적화"하지 말 것
  • 히스토리를 슬라이스로 자르지 말 것
  • `.env` 변경 후 `get_settings.cache_clear()`
  • `services/`·`electron-ui/`를 `src/` 같은 폴더로 감싸지 말 것
  • "이번 턴"을 판단할 땐 `current_turn_messages()`를 쓸 것
  • 테스트에서 소스를 열 땐 `encoding="utf-8"`를 붙일 것
  • `/voice`의 `thread_id`·`use_tts`에서 `Form(...)`을 빼지 말 것
  • 클릭 도구에 좌표 인자(`x`, `y`)를 추가하지 말 것
  • `main.py`의 `allow_origins=["null"]`과 OPTIONS 면제를 "정리"하지 말 것
  • 계획 상태(`plan`/`plan_cursor`)를 턴 너머로 새게 하지 말 것
