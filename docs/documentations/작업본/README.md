> 📍 상위: [docs/README.md](../../README.md) · 양식 원본: [`../`](../) 의 hwp 8개

## 왜 md인가

hwp/워드는 편집기를 붙들고 있어야 하고, **토큰과 시간을 크게 먹는다.**
그래서 **내용은 여기 md에서 관리**하고, **제출 직전에 한 번만** 양식 hwp로 옮긴다.
양식(폰트·목차·번호)은 제출 시점의 형식 문제이고, **지금 필요한 건 내용**이다.

## 제출 절차 (마감 직전 1회)

1. 이 md들의 `⬜ TODO` 가 0개인지 확인한다
2. 양식 hwp를 열고 **가이드라인 페이지를 삭제**한다 (양식이 그렇게 지시한다)
3. md 내용을 표에 옮긴다 — **목차는 절대 수정하지 않는다.**
   해당 없는 절은 **삭제하지 말고 "해당 없음"** 으로 적는다
4. 공통 형식: **맑은고딕** · 제목1 20pt · 제목2 14pt · 제목3 12pt · 제목4 11pt ·
   본문 10pt · 줄간격 150%(D05·D06은 130%) · 목차 11pt/160% · **페이지 번호 필수**
5. 문서번호 `20__-TeamName-Doc-0__` 부여

## 양식이 요구하는 문체 규칙 (전 문서 공통)

- **모호한 표현 금지** — "~할 수도 있다" 를 쓰지 않는다
- 모든 문장에 **주어·동사·목적어**가 있어야 한다
  (❌ "데이터를 입력받아야 한다" → ✅ "사용자가 음성으로 명령을 입력한다")
- **개조식**으로 짧게 끊어 쓴다
- 표·그림에 **번호**를 붙이고 본문에서 인용한다
