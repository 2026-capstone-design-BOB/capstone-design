**[1] `is_prompt_echo()` @ `services/stt.py`**

| 항목 | 내용 |
|---|---|
| 목적 | 음성 인식 결과가 **우리가 넣은 프롬프트의 연속 조각**인지 판정한다 |
| 입력 | 인식된 문자열 |
| 출력 | 반추이면 참 |
| 왜 필요한가 | 2026-09-14 실기에서 **승인 대기가 이것 하나에 깨졌다.** 원인은 «인식 환각»이 아니라 «프롬프트 반추»였다 |
| 주의 | 이 판정만으로 막지 않는다. **어절 상한**이 2층으로 함께 있다 — 한 층이 다른 층을 대신하지 못한다 |

**[2] `_looks_like_command()` @ `core/graph.py`**

| 항목 | 내용 |
|---|---|
| 목적 | 승인 대기 중 들어온 입력을 **«새 명령»으로 볼지** 판정한다 |
| 입력 | 사용자 입력 문자열 |
| 출력 | 새 명령이면 참 → 대기 중이던 계획을 **버린다** |
| 왜 필요한가 | 계획을 안 버리면 새 명령이 *«지금은 2단계: 파일 삭제»* 지시를 받는다 |
| 주의 | 🚨 **이 분기에서 계획을 지우는 줄을 지우면** 취소 플래그가 새어 «삭제해 놓고 취소했다고 답하는» 사고가 재현된다 |

**[3] `is_learnable_utterance()` @ `core/command_cache.py`**

| 항목 | 내용 |
|---|---|
| 목적 | 어떤 발화를 캐시에 **학습할지** 결정한다 |
| 입력 | 발화 · 이번 턴의 도구 호출 |
| 출력 | 학습 가능하면 참 |
| 차단 대상 | **지시대명사**("그거") · **승인 응답**("응") · **복합 명령**(도구 2개 이상) |
| 왜 필요한가 | 학습하면 다음 턴에 **다른 대상**에 같은 동작을 한다. 되돌릴 수 없는 도구면 사고가 된다 |

**[4] 승인 배치 판정 @ `core/graph.py` (`hitl`)**

| 항목 | 내용 |
|---|---|
| 목적 | 위험한 도구 호출이 **여러 개**일 때 **한 번에** 묻는다 |
| 입력 | 이번 턴의 도구 호출 목록 |
| 출력 | 대상 이름을 **전부 포함**하고 개수를 밝힌 질문 1개 |
| 왜 필요한가 | 나눠 물으면 사용자가 두 번째를 «아까 그거»로 읽고 승인한다 |

**[5] 「이번 턴」 판정 — `current_turn_messages()`**

| 항목 | 내용 |
|---|---|
| 목적 | **이번 턴**에 일어난 일만 본다 |
| 왜 필요한가 | 전체 히스토리를 훑으면 **과거 턴의 도구 오류**가 현재 응답과 캐시 학습을 오염시킨다 |

### 3.3 DB 스키마 명세

**해당 없음.** 본 시스템은 DBMS를 사용하지 않는다.
상태는 JSON 파일(`cache/command_cache.json`)과 LangGraph `MemorySaver`(메모리)로 관리한다.

> 🔑 근거: 로컬 우선 설계이며, 사용자 데이터를 외부에 저장하지 않는다는 요구(R-03)를 따른다.

## 5. 기타 구현 참고 사항 — **어기면 깨지는 것**

> 🚨 **원본은 [`CLAUDE.md` § 절대 규칙](../../../CLAUDE.md)(11개)이다.** 여기에는
> **왜 그런지**를 한 줄로 줄여 옮긴다. 근거 전문은 각 설계 문서에 있다.

| # | 제약 | 어기면 |
|---|---|---|
| 1 | 그래프 노드를 async로 바꾸지 않는다 | 승인(`interrupt`)이 불안정해진다 |
| 2 | 캐시 적중을 조기 return으로 «최적화»하지 않는다 | 캐시 결과가 대화에 안 쌓여 **다음 턴 맥락이 붕괴**한다 |
| 3 | 히스토리를 슬라이스로 자르지 않는다 | 도구호출·결과 **쌍이 깨져** API 오류가 난다 |
| 4 | `.env`를 바꾼 뒤 **설정 캐시**를 비운다 | 설정을 고쳐도 **옛 값이 계속 쓰인다**(명령 캐시와 다른 것이다) |
| 5 | `services/`·`electron-ui/`를 다른 폴더로 감싸지 않는다 | Electron이 직접 참조하는 경로가 끊긴다 |
| 6 | 「이번 턴」은 `current_turn_messages()`로 판단한다 | 과거 턴 오류가 현재 응답·학습을 오염시킨다 |
| 7 | 테스트에서 소스를 열 때 인코딩을 지정한다 | 한글 소스에서 디코딩 오류가 난다 |
| 8 | `/voice`의 대화 식별자를 폼 필드로 받는다 | **음성과 텍스트가 다른 대화**가 된다(§3.4 경고) |
| 9 | 클릭 도구에 좌표 인자를 추가하지 않는다 | 모델이 좌표를 **지어내고**, 틀린 곳을 정확히 클릭한다. 클릭은 되돌릴 수 없다 |
| 10 | 로컬 전용 CORS 설정을 «정리»하지 않는다 | 공격자가 아니라 **UI 자신이** 막힌다. 실질 방어는 토큰이다 |
| 11 | 계획 상태를 턴 너머로 흘리지 않는다 | 승인 대기 중 새 명령이 **지난 계획의 지시를 받는다** |

> 🔑 **이 표가 D06에서 가장 실용적인 절이다.** 전부 **실제로 한 번씩 깨져 본 것**이고,
> 그래서 규칙으로 고정됐다. 신규 참여자가 가장 먼저 읽어야 할 곳이다.
