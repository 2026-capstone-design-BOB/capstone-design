## 작품 설명

Pluiz는 사용자가 한국어로 말한 명령을 이해하여 Windows PC를 직접 제어하는 데스크톱 AI 에이전트이다.
사용자가 호출어 "플루이즈"를 말하거나 마이크 버튼을 누르면 음성을 인식하고,
LangGraph 기반 에이전트가 41개의 도구 중 적절한 것을 선택하여 실행한다.
되돌릴 수 없는 동작은 실행 전에 사용자에게 승인을 요청한다.

## 사용자 유형

- **주요 사용자** : 키보드·마우스 조작이 불편하거나 반복 작업을 음성으로 처리하려는 Windows PC 사용자
- **보조 사용자** : 화면 내용 파악·설정 위치 안내가 필요한 PC 초보 사용자
- **관리자** : 시스템을 설치하고 API 키·호출어를 설정하는 담당자

## 운영 개념

1. Pluiz는 Windows PC에 설치되어 로컬에서 실행된다. FastAPI 서버(:8765)와 Electron 오버레이 UI로 구성된다.
2. 사용자의 음성은 온라인일 때 Google STT, 오프라인일 때 로컬 Whisper로 인식된다.
3. 명령 해석은 Gemini 2.0 Flash가 수행한다. 단, 이전에 학습된 명령은 **LLM을 호출하지 않고** 캐시에서 즉시 실행한다.
4. 인터넷이 없으면 캐시에 등록된 명령만으로 핵심 기능을 수행한다.
5. 화면 이해가 필요한 명령은 스크린샷을 Vision 모델에 전달하여 처리한다.

## 작품의 주요 기능

1. 음성으로 응용 프로그램을 실행·종료·전환한다.
2. 음성으로 시스템을 제어한다(볼륨·밝기·전원·창 배치 등).
3. 음성으로 파일을 찾고 열고 만들고 삭제한다. **삭제는 사용자 승인 후에만 실행한다.**
4. 현재 화면을 해석하여 무엇이 표시되어 있는지 설명한다.
5. 사용자가 찾는 UI 요소의 위치를 화면 위에 표시하여 길을 안내한다.
6. 화면 변화를 감시하여 지정한 상황이 발생하면 사용자에게 알린다.
7. 여러 동작이 포함된 복합 명령을 계획으로 분해하여 순차 실행한다.
8. 자주 쓰는 명령을 학습하여 다음부터 LLM 없이 즉시 실행한다.
9. 학습된 캐시와 설정을 파일 하나로 내보내고 가져온다.

## 기타 개발 시 고려사항

1. 되돌릴 수 없는 동작(파일 삭제·좌표 클릭·전원 제어)은 **반드시 사용자 승인을 거친다.**
2. OWASP LLM Top 10을 참고하여 **5층 방어**를 적용한다(토큰 인증·입력 가드·도구 제한·승인·출력 검증).
3. 인터넷 연결이 없어도 핵심 기능이 동작해야 한다.
4. 사용자의 화면을 다루므로 데이터를 외부 서버에 저장하지 않는다. **로컬 우선 설계를 유지한다.**
