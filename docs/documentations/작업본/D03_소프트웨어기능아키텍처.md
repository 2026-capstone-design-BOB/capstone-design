## 2. 기능 아키텍처

### 2.1 액터 목록

| 액터명 | 역할 | 참고 |
|---|---|---|
| 사용자(User) | 음성 또는 텍스트로 명령을 입력하고, 위험 동작에 대한 승인·거부를 결정한다 | 주 액터 |
| 관리자(Admin) | API 키·호출어·TTS 사용 여부를 설정하고, 캐시를 내보내기/가져오기 한다 | 실제로는 같은 사람일 수 있다 |
| LLM 서비스(Gemini) | 명령을 해석하여 호출할 도구와 인자를 결정한다. 화면 이미지를 해석한다 | 외부 시스템 |
| STT 서비스(Google) | 음성을 텍스트로 변환한다. 실패 시 로컬 Whisper로 대체된다 | 외부 시스템 |
| Windows OS | 앱 실행·창 제어·파일 조작·시스템 설정 변경을 실제로 수행한다 | 외부 시스템 |

### 2.3 사용사례 목록

| 주제ID | 사용사례 | 액터 | 설명 |
|---|---|---|---|
| T-01 | 음성으로 명령하기 | 사용자 | 호출어 또는 버튼으로 녹음을 시작하고, 음성을 텍스트로 변환하여 명령으로 전달한다 |
| T-02 | 응용 프로그램 제어 | 사용자 | 앱을 실행·종료·전환하고, 실행 중인 앱 목록을 조회한다 |
| T-03 | 시스템 제어 | 사용자 | 볼륨·밝기·창 배치·전원 등 시스템 상태를 변경한다 |
| T-04 | 파일 관리 | 사용자 | 파일을 찾고 열고 만들고 삭제한다. 삭제는 승인을 거친다 |
| T-05 | 정보 조회 | 사용자 | 웹 검색·날씨·시간 등 외부 정보를 조회한다 |
| T-06 | 화면 이해 | 사용자 | 현재 화면에 무엇이 있는지 설명하고, 특정 UI 요소를 찾는다 |
| T-07 | 화면 길안내 | 사용자 | 찾은 UI 요소의 위치를 화면 위에 표시하고 확대한다 |
| T-08 | 화면 감시 | 사용자 | 지정한 변화가 발생할 때까지 화면을 감시하고 알린다 |
| T-09 | 위험 동작 승인 | 사용자 | 되돌릴 수 없는 동작에 대해 실행 전 승인·거부를 결정한다 |
| T-10 | 복합 명령 처리 | 사용자 | 두 가지 이상의 동작이 포함된 명령을 계획으로 분해하여 순차 실행한다 |
| T-11 | 명령 학습·재사용 | 사용자 | 성공한 명령을 학습하여 다음부터 LLM 없이 즉시 실행한다 |
| T-12 | 오프라인 동작 | 사용자 | 인터넷이 없을 때 학습된 명령만으로 핵심 기능을 수행한다 |
| T-13 | 설정 및 이식 | 관리자 | API 키·호출어를 변경하고, 캐시·설정을 파일로 내보내고 가져온다 |

## 3. 기타 요구사항

- 되돌릴 수 없는 동작은 승인 없이 실행되지 않아야 한다.
- 오프라인 상태에서 응답이 지연되지 않아야 한다(LLM 호출을 생략한다).
- 도구 실행이 실패한 경우 성공했다고 응답하지 않아야 한다.
