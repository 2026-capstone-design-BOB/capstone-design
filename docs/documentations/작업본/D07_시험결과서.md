본 과정에서는 단위 테스트와 통합 테스트를 별도 단계로 분리하지 않는다.

|---|---|
| Gemini API 응답 내용의 정확성 | 외부 LLM 서비스의 출력이며 본 시스템의 구현 범위가 아니다. 단, **도구 선택 결과**는 테스트 대상에 포함한다 |

## 4. 테스트 예외사항

### 4.1 중단 기준과 재개 조건 (표 4)

| 중단 기준 | 재개 조건 |
|---|---|
| 승인 대기 상태에서 시스템이 응답하지 않는 경우 | 원인을 수정한 뒤 해당 테스트 케이스부터 다시 수행한다 |
| 테스트 중 사용자의 실제 파일이 삭제될 위험이 확인된 경우 | **즉시 중단**한다. 테스트 전용 파일로 교체한 뒤 처음부터 다시 수행한다 |
| 외부 API(Gemini·Google STT)가 응답하지 않는 경우 | 서비스 복구 후 해당 케이스부터 재개한다. 오프라인 경로 테스트는 계속 진행한다 |
| 테스트 실행이 사용자의 실제 캐시 파일을 변경한 경우 | 캐시를 복원한 뒤 처음부터 다시 수행한다 |
