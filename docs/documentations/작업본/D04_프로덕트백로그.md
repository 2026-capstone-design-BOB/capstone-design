## 3. 기타 사항

- **R-01** : 되돌릴 수 없는 동작은 승인 없이 실행되지 않아야 한다. (무조건 요구사항)
- **R-02** : 도구 실행이 실패한 경우 성공했다고 응답하지 않아야 한다.
- **R-03** : 사용자 데이터를 외부 서버에 저장하지 않는다.
- **R-04** : 오프라인 상태의 응답 시간이 온라인 대비 크게 지연되지 않아야 한다.
