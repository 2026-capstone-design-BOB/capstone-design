## 시스템 설명

Pluiz는 한국어 음성 명령으로 Windows PC를 제어하는 데스크톱 AI 에이전트이다.
LangGraph 기반 에이전트가 41개 도구 중 적절한 것을 선택해 실행하며,
되돌릴 수 없는 동작은 실행 전에 사용자 승인을 받는다.
자주 쓰는 명령은 학습되어 LLM 호출 없이 즉시 실행되므로 인터넷 없이도 핵심 기능이 동작한다.

## 시스템 운영 환경

- Windows 11 · Python(conda 환경) · Node.js/Electron
- FastAPI 로컬 서버(:8765) + Electron always-on-top 오버레이 UI
- 외부 서비스: Google Gemini 2.5 Flash(해석·Vision) · Google STT(온라인 음성 인식)
- 오프라인 대체: faster-whisper(로컬 STT) · 명령 캐시

## 개발 적용 기술

| 영역 | 기술 |
|---|---|
| 에이전트 | LangGraph `StateGraph` · Human-in-the-Loop(`interrupt`) |
| 보안 | OWASP LLM Top 10 기반 5층 방어 |
| 음성 | openWakeWord 임베딩 백본 + 자체 KWS 헤드 · 하이브리드 STT · edge-tts |
| 화면 이해 | Gemini Vision · UI 요소 좌표 인식 · 화면 변화 감시 |
| 성능 | 명령 캐시(퍼지 매칭) · 오프라인 LLM 단락 |

## 시스템 활용 효과

> ✅ **2026-09-18 작성.** 수치는 **전부 실측값**이고, 잰 문서를 각 항목에 달았다.
> ⚠️ **최종 제출 전에 다시 잰다** — 아래 숫자는 **기능 동결 전**의 값이고,
> 실사용 한 달(2026-10-31~)이 끝나면 같은 스크립트로 갱신한다.

**1) 접근성 — 「어떻게 할지」를 몰라도 된다**

- 사용자는 **원하는 결과만** 말한다. 절차를 외우지 않는다.
- Windows 「음성 액세스」로 볼륨을 바꾸려면 *"설정 열어"* → *"숫자 표시"* →
  *"37 클릭"* → *"슬라이더 오른쪽 5번"* 의 **4단계**가 필요하다.
  Pluiz는 *"볼륨 30으로 맞춰줘"* **한 마디**로 수행한다.
- 정해진 문법이 없으므로 **같은 뜻의 다른 말**로 명령해도 동작한다.
  (음성 액세스는 명령어가 한 글자만 달라도 인식하지 않는다.)

**2) 응답 속도 — 학습된 명령은 18배 빠르다**

| 구분 | 중앙값 |
|---|---|
| LLM을 거치는 턴 | **3.26초** |
| 학습된 명령(LLM 0회) | **0.18초** |
| **차이** | **18배** |

- 실사용 **143턴 중 32턴(22.4%)** 이 LLM 호출 없이 끝났다.
- **같은 값이 두 번 재현됐다** — 2026-09-10 측정은 21.1%(38턴 중 8턴)였다.
  다른 날·다른 로그에서 **1.3%p 차이**다.
- 인터넷이 끊긴 채 실패하던 턴도 **8.01초 → 0.17초**로 줄었다(LLM 호출을 생략한다).

**3) 오프라인 동작 — 로컬 명령의 76.9%가 인터넷 없이 실행된다**

| 표본 | 결과 |
|---|---|
| 고정 20문장 | **10개 / 20 (50.0%)** |
| 그중 **로컬 명령만**(날씨·웹검색·잡담 제외) | **10개 / 13 (76.9%)** |
| 실제 로그 120발화 | **25개 (20.8%)** |

- 인터넷이 없을 때 **LLM을 아예 호출하지 않으므로** 응답이 지연되지 않는다.

**4) 안전성 — 되돌릴 수 없는 동작은 승인 없이 실행되지 않는다**

- 파일 삭제 등 비가역 동작은 **실행 전에** 무엇을 할지 밝히고 승인을 받는다.
- 승인 경로에 대한 자동화 회귀 테스트 **179건**이 상시 실행된다
  ([D07 §3.1](D07_시험결과서.md) E-21·E-22 — 140 + 8 + 31).
- 화면 인식은 **없는 것을 지어내지 않는다** — 기준선 15건 중 「없음」 3건을 포함해
  **환각 0건**이었다. ⚠️ **다만 이 자는 쉬웠다**(15/15). 더 어려운 자로 다시 잰다.

> 🔑 **넷 중 «자랑»이 아닌 것이 하나 있다.** 3)의 20.8%는 실제 로그 기준이고,
> 50.0%보다 낮다. **낮은 쪽을 지우지 않았다** — 표본이 다르면 값이 다르다는 사실 자체가
> 이 프로젝트가 숫자를 다루는 방식이다.
