## 지금 상태 (2026-09-10 기준)

**Pluiz** — 한국어 음성 명령으로 Windows PC를 제어하는 AI 에이전트. 졸업 캡스톤.

2026.06.15 데모 완료. 이후 강의 개념(LangGraph·HITL·OWASP 가드레일)을 구조에 적용하는
**Milestone 1**을 진행했고, **2026-09-02 라이브 실측(FAIL 0)으로 M1 완료를 확인**했다.
같은 날 코드 리뷰로 **HITL 오승인·"턴 경계" 결함을 수정**했고(mock 검증 완료,
**실기 확인은 남음** → [TASKS.md](TASKS.md) ①), 이어서 **BL-14(로컬 API 무인증)를
막아 보안이 4층 → 5층**이 됐다 → [ARCHITECTURE § 보안](ARCHITECTURE.md#보안--5층-방어).
**2026-09-03에 Phase 2(화면 이해)의 마지막 항목인 화면 변화 모니터링까지 넣어
9월 로드맵이 코드상으로는 닫혔다** — 보기 → 찾기 → 누르기 → 지켜보기.
**2026-09-04에 Vision 경로를 라이브로 처음 검증했고**(V-01~V-04 통과),
그 과정에서 **감시가 실사용에서 한 번도 켜진 적이 없다는 걸 발견해 고쳤다**(BL-19).
**2026-09-07에 다섯 기능이 전부 실기를 통과해 Phase 2가 진짜로 닫혔다** — 좌표 클릭·화면 감시 포함.
가는 길에 결함 셋을 만나 다 고쳤다: **BL-22**(프리필터가 글자 한 줄을 놓쳤다) ·
**BL-21**(계획이 건너뛴 단계를 완료로 세고 **캐시에 학습**했다) · `get_running_apps`가
계산기를 못 보던 것. **셋 다 mock이 초록인 채로 살아 있었다.**
10월 항목이던 **계획 수립도 라이브를 통과해 기본 켜짐**이 됐다
→ [M3](design/M3_계획수립노드.md) · [M3-1](design/M3-1_단계완료판정.md) · [M3-2](design/M3-2_미시도_단계_재시도.md) · [ROADMAP.md](ROADMAP.md).
**2026-09-09에 ⭐ 2주차(포인팅·확대 + 설정창 길안내)가 닫혔다** — *"그게 어딨지"* 하면
**화면에 고리로 표시**하고, `zoom=True`면 **돋보기**로 확대한다. 창이 꺼져 있으면 열고
최소화면 되살린다 → [M4](design/M4_포인팅_확대.md).

**BL-26**(안 한 걸 했다고 말함 — 유령 창)을 고쳤다.

## 문서 원칙

**한 사실은 한 문서에만 쓴다.**

과거에 `CLAUDE.md`가 코드와 크게 어긋난 적이 있는데, 원인은 같은 내용이 여러 문서에 중복돼 한쪽만 갱신됐기 때문이다. 그래서:

- 구조는 `STRUCTURE.md`, 동작은 `ARCHITECTURE.md`, 절차는 `WORKFLOW.md`가 **단독으로** 책임진다.
- [`../CLAUDE.md`](../CLAUDE.md)는 내용을 담지 않고 **여기로 안내만** 한다.
- [`../README.md`](../README.md)는 외부 방문자용 소개이므로 상세를 담지 않고 이 허브로 링크한다.
- 중복이 필요해 보이면, 중복 대신 **링크**한다.
