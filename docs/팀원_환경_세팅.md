# 팀원 환경 세팅 — 다른 PC에서 Pluiz를 돌리기까지

> 📍 [문서 허브](README.md) · 구글 연결은 [구글_연결.md](구글_연결.md) · 협업 규칙은 [CONTRIBUTING.md](CONTRIBUTING.md)

**대상**: 이 저장소를 처음 받는 Windows PC.
**걸리는 시간**: 약 40분 (받고 설치하는 시간 포함, 구글 연결 15분 별도).

이 PC는 **돌려 보고 피드백을 주는 용도**입니다. 코드를 고치거나 커밋하지 않습니다(§8).

---

## 0. Claude Code에게 맡기는 법

저장소 폴더에서 Claude Code를 열고 이렇게 말하면 됩니다.

    docs/팀원_환경_세팅.md 보고 이 PC에 환경 세팅해줘

다만 **§1 · §3은 사람이 해야 합니다.** Claude Code가 대신 못 하는 일입니다 —
설치 마법사 클릭, 웹 콘솔에서 키 발급, 브라우저 로그인 동의.
나머지(§4 · §5)는 맡겨도 됩니다.

> 🚨 **폴더가 비어 있으면 이 문서도 없습니다.** §2를 먼저 하세요.
> 저장소를 받기 전에 Claude Code를 열면 읽을 docs가 없습니다.

## 1. 사람이 먼저 — Claude Code가 못 하는 것

| 무엇 | 어디서 | 됐는지 확인 |
|---|---|---|
| **Miniconda** (또는 Anaconda) | <https://www.anaconda.com/download/success> | Anaconda Prompt 에서 `conda --version` |
| **Node.js** (LTS) | <https://nodejs.org/> | `node --version` |
| **Git** | <https://git-scm.com/> | `git --version` |
| 마이크 | — | 음성으로 쓸 거면. 텍스트만 쓸 거면 없어도 됩니다 |

⚠️ **Windows 10/11 전용입니다.** PC를 조작하는 도구들이 Windows API를 직접 씁니다.

📌 **설치 뒤에는 Anaconda Prompt를 쓰세요.** 일반 `cmd`나 Git Bash에서는
`conda` 가 잡히지 않거나, 잡혀도 §6 ①의 문제가 납니다.

## 2. 저장소 받기 — 🚨 브랜치를 바꿔야 합니다

```bash
git clone https://github.com/2026-capstone-design-BOB/capstone-design.git
cd capstone-design
git checkout dev/post-demo
```

🚨 **마지막 줄을 빠뜨리면 100커밋 이상 옛날 코드를 받습니다.**
`main` 은 1학기 데모 시점에 멈춰 있고, 지금 작업은 전부 `dev/post-demo` 에 있습니다.
구글 연결·일정 고치기·화면 짚기 같은 것이 `main` 에는 아예 없습니다.

확인:

```bash
git branch --show-current     # dev/post-demo 가 나와야 합니다
```

## 3. 준비물 둘 (사람 몫)

### 3-1. LLM API 키

기본은 **Gemini** 입니다 — <https://aistudio.google.com/apikey> 에서 발급합니다.
(Claude·OpenAI도 쓸 수 있습니다. `.env` 의 `LLM_PROVIDER` 로 고릅니다.)

### 3-2. 구글 자격증명 — 일정·메일을 쓸 거면

[구글_연결.md](구글_연결.md) 를 그대로 따라합니다 (약 15분).
받은 JSON 파일을 **저장소 루트에 `calendar_credentials.json` 이름으로** 둡니다.

🚨 **본인 계정으로 각자 발급받습니다.**
변소윤 님의 `calendar_token.json` 을 복사해 오면 안 됩니다 — 그 파일은
**그 계정의 일정과 메일을 읽는 열쇠**입니다. 자격증명도 토큰도 저장소에
올라가지 않습니다(`.gitignore`).

📌 일정·메일을 안 쓸 거면 이 단계를 건너뛰어도 나머지는 전부 동작합니다.

## 4. 설치 — 여기부터 Claude Code에게 맡겨도 됩니다

**Anaconda Prompt** 에서 저장소 폴더로 간 뒤:

```bat
conda create -n pluiz python=3.11 -y
conda activate pluiz
pip install -r requirements.lock.txt
playwright install chromium
cd electron-ui && npm install && cd ..
copy .env.example .env
```

마지막으로 `.env` 를 열어 `GEMINI_API_KEY=` 뒤에 §3-1의 키를 붙여넣습니다
(따옴표 없이 값만).

> 📌 `requirements.txt` 가 아니라 **`requirements.lock.txt`** 를 쓰는 이유는 §6 ②에 있습니다.

## 5. 됐는지 확인

### 5-1. 코드 쪽 — 키도 마이크도 없이 됩니다

```bat
conda activate pluiz
set PYTHONIOENCODING=utf-8
python scripts/run_mock_suite.py
```

**`실패 0`** 이 나오면 설치는 끝난 것입니다.
여기서 실패가 나면 LLM 키 문제가 아니라 **설치가 덜 된 것**입니다(§6 ①을 보세요).

### 5-2. 실제로 띄워 보기

```bat
launch.bat
```

서버 창과 UI 창이 하나씩 뜹니다. 화면에 뜬 알약 모양을 더블클릭하면 녹음,
펼치면 텍스트로 명령할 수 있습니다.

- *"메모장 열어줘"* — 키 없이 캐시로도 도는 명령입니다
- *"오늘 일정 알려줘"* — 구글 로그인이 안 돼 있으면 **브라우저가 알아서 뜹니다.**
  거기서 한 번 로그인하면 그 뒤로는 안 묻습니다

## 6. `setup.bat` 을 그대로 믿지 마세요 — 구멍 셋

저장소에 `setup.bat` 이 있지만, 새 PC에서는 **조용히 어긋납니다.**
그래서 §4를 직접 돌리는 쪽을 권합니다.

| | 무엇 | 왜 문제인가 |
|---|---|---|
| ① | 일반 `cmd` 에서는 `conda activate` 가 안 먹습니다 | 🚨 **실패해도 다음 줄의 `pip install` 이 그냥 돕니다.** 패키지가 **엉뚱한 python(anaconda base)** 에 깔리고, 나중에 `python main.py` 가 `ModuleNotFoundError: langgraph` 로 죽습니다. 원인이 한참 앞 단계에 있어서 찾기 어렵습니다 |
| ② | `requirements.txt`(하한)를 깝니다 | 그 파일은 *«왜 이 패키지가 필요한가»* 를 적는 문서라 `>=` 만 있습니다. 설치할 때마다 최신이 들어와 **코드를 하나도 안 고쳐도 어느 날 깨집니다.** 재현되는 설치는 `requirements.lock.txt` 입니다 |
| ③ | `playwright install` 과 `npm install` 을 안 합니다 | `launch.bat` 이 첫 실행에 하긴 합니다. 다만 그때 수백 MB를 받느라 **처음 띄우는 사람은 멈춘 줄 압니다** |

## 7. 저장소에 없는 것 — 각 PC에서 생깁니다

| 무엇 | 어떻게 생기나 |
|---|---|
| `.env` | §4에서 복사하고 키를 넣습니다 |
| `calendar_credentials.json` | §3-2 — 사람이 둡니다 |
| `calendar_token.json` | 첫 구글 로그인 때 자동으로 생깁니다 |
| `electron-ui/node_modules/` | `npm install` |
| 음성 인식 모델(Whisper) | 첫 음성 입력 때 자동으로 내려받습니다 (인터넷 필요) |
| `models/embed/` (선택) | `python scripts/fetch_embed_model.py` — **없어도 서버는 그대로 뜹니다** |

반대로 **저장소에 들어 있는 것**: 웨이크워드 모델(`services/wakeword_model.npz`).
목소리 14개로 학습해 **처음 듣는 목소리도 98% 잡으므로**, 팀원 목소리로 다시
학습할 필요가 없습니다. → [design/M2_웨이크워드_전용모델.md](design/M2_웨이크워드_전용모델.md)

## 8. 이 PC에서는 커밋하지 않습니다

git 작업(커밋·푸시·브랜치)은 **변소윤이 합니다.** 이 PC는 돌려 보는 쪽입니다.

- 쓰다가 이상한 점이 보이면 **코드를 고치지 말고 적어서 전달**하세요
  → [teamwork/사용_피드백.md](teamwork/사용_피드백.md)
- 최신 상태를 다시 받으려면 `git pull` 만 하면 됩니다
  (`.env` 와 토큰은 추적되지 않으므로 덮어쓰이지 않습니다)

## 막혔을 때

| 증상 | 먼저 볼 곳 |
|---|---|
| `ModuleNotFoundError: langgraph` | §6 ① — 다른 python에 깔렸습니다. `conda activate pluiz` 뒤 `python -c "import sys; print(sys.executable)"` 로 어느 python인지 봅니다 |
| 테스트 출력이 한글에서 깨진다 | `set PYTHONIOENCODING=utf-8` |
| 테스트가 엉뚱하게 실패한다 | Git Bash 말고 **Anaconda Prompt** 에서 돌립니다 → [WORKFLOW.md](WORKFLOW.md) |
| 도구가 조용히 안 된다 | `python tests/test_dependencies.py` |
| UI는 뜨는데 명령이 안 먹는다 | 서버 창(`:8765`)이 살아 있는지 · `logs/pluiz.log` |
| 일정·메일이 계속 *"로그인이 안 됐어요"* | [구글_연결.md](구글_연결.md) §3 — 테스트 사용자에 본인 계정이 들어 있는지 |
| 웨이크워드가 안 들린다 | `.env` 의 `WAKEWORD_ENERGY` 를 낮춥니다(마이크가 작을 때) |
