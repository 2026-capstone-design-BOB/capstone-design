## 1. 이름 바꾸는데 「삭제」라고 묻지 않는가 (2분)

**어제 이렇게 물었습니다** — 동작은 맞았는데 **문구가 거짓말**이었습니다.

```

🤖 '회의록.txt' 파일을 정말 삭제할까요? (휴지통으로 갑니다)   ← 삭제가 아닌데
```

### 할 것

> **"바탕화면 회의록.txt 이름을 주간보고.txt 로 바꿔줘"**

### 봐야 할 것

승인 질문에 **「삭제」도 「휴지통」도 없어야** 합니다. 이런 식이어야 합니다.

```
'회의록.txt' 이름을 바꿀까요? (파일은 그대로 있고 이름만 바뀌어요)
```

### 적어 주실 것

```
승인 질문에 뭐라고 떴나 (그대로 옮겨 주세요):
→ '회의록.txt' 파일을 이름을 바꿀까요? (파일은 그대로 있고 이름만 바뀌어요)

## 3. 알림 안내에 세 가지가 다 있는가 (1분)

**어제는 ①만 나왔습니다.** 도구는 세 가지를 다 돌려주는데 모델이 요약하면서 ②③을 버렸습니다.
이번엔 **도구가 만든 문장을 그대로** 내보내게 했습니다.

### 할 것

> **"1분 뒤에 물 마시라고 알려줘"**

### 봐야 할 것 — 셋이 다 있어야 합니다

- ① **언제** 알려주는지
- ② **"Pluiz 를 닫으면 이 알림도 사라져요"**
- ③ **취소하는 법** ("알림 취소해줘" 라고 하라는 안내)

### 적어 주실 것

```
답을 그대로 옮겨 주세요:
→✓ 1분 뒤에 '물 마시기' 라고 알려드릴게요.
⚠️ Pluiz 를 닫으면 이 알림도 사라져요.
취소하려면 "알림 취소해줘" 라고 말씀해 주세요.

①②③ 중 몇 개가 있었나:
→ 3개 다 있었음

결과:  성공 
메모:
```

> ⏱ 1분 뒤 알림이 울리는 건 이미 확인됐으니 안 기다리셔도 됩니다.
> 끝나면 **"알림 취소해줘"** 로 꺼 주세요.

## 5. 내용 없이 덮어쓰라고 하면 파일이 비워지는가 (1분)

**가장 위험했던 것입니다.** 「덮어써 줘」에 내용이 없으면 **파일이 그냥 비워질 수 있었습니다.**

### 할 것

바탕화면에 `회의록.txt`(또는 1번에서 이름 바꾼 `주간보고.txt`)가 있는 상태에서

### 봐야 할 것

- **되물어야** 합니다 — "무슨 내용으로 덮어쓸까요?"
- 🚨 **그리고 파일이 그대로 있어야 합니다.** 열어서 내용이 남아 있는지 확인해 주세요

## 6. 맡긴 일이 되묻고 끝나는가 (3분 — 걸어두고 기다리기)

**어제는 이렇게 끝났습니다** — 검색 도구를 가지고 있으면서도 안 쓰고 되물은 뒤 «완료»로 닫혔습니다.

```
👤 전기차 보조금 세 군데 찾아서 정리해줘, 끝나면 알려줘
🤖 (뒤에서) 어떤 지역의 전기차 보조금을 찾아드릴까요?   ← 답할 사람이 없는데
```

### 할 것

> **"전기차 보조금 세 군데 찾아서 정리해줘, 오래 걸려도 되니까 끝나면 알려줘"**

### 봐야 할 것

- 바로 **「뒤에서 할게요」** 로 끝납니다
- 🚨 **요청하지 않은 화면 감시(👁 배지)가 붙으면 안 됩니다** ← 어제 이게 같이 붙었습니다
- 끝나면 먼저 말을 겁니다. 결과가 **되묻는 질문이 아니라 내용**이어야 합니다
- 지역 같은 걸 모르면 **가정하고 진행한 뒤 「가정: …」 을 같이 말해야** 합니다

### 적어 주실 것

```
👁 배지가 안 붙었나:   예 / 아니오
→ 그거 말고 모래시계 배지가 붙었고 명령 완료 이후에 사라졌다.

결과로 뭐가 왔나 (앞부분만 옮겨 주세요):
→✓ '전기차 보조금 세 군데 찾아서 엑셀로 정리' 은(는) 뒤에서 할게요. 끝나면 바로 알려드릴게요.
하시던 일 보고 계셔도 돼요. 최대 10분까지 해보고, 그때까지 못 끝내면 못 끝냈다고 알려드릴게요.
⚠️ Pluiz 를 닫으면 하던 것도 사라져요.
🤖
지자체 보조금은 지역별로 상이하며, 일부 차종은 정보가 없어 비워두었습니다.

되묻는 질문이었나, 내용이었나:
→ 내용이었음. 

결과:  성공 
메모: 근데 엑셀로 하는건 무슨 근거로 그렇게 정리한건지 궁금
```

> 🔑 **못 하겠으면 「못 했다」고 말하게** 해 뒀습니다. 그 문장이 오는 것도
> **성공입니다** — 어제처럼 질문을 답인 척 내놓는 것보다 낫습니다.

## 7. 메모장 감시가 상태표시줄을 글자로 세는가 (2분)

**어제 지적하신 것입니다** — 「상단 탭 내용이나 하단 줄 개수나 Windows CRLF, UTF-8 같은
부분도 글자로 인식됨」. 창을 열기만 해도 늘 거기 있는 것들이라 그걸 세면
아무 일도 안 일어났는데 부릅니다.

### 할 것

1. **메모장을 빈 채로** 띄웁니다
2. > **"메모장 지켜보다 글자 생기면 알려줘"**
3. **아무것도 치지 말고 30초 기다립니다** ← 여기가 핵심입니다
4. 그 다음 아무 글자나 칩니다

### 봐야 할 것

- 🚨 **3번에서 아무 말도 없어야 합니다.** 빈 메모장인데 「글자가 보여요」라고 하면 그대로입니다
- 4번에서는 **알려줘야** 합니다 (감시가 죽은 게 아니어야 하니까요)

### 적어 주실 것

```
(3) 아무것도 안 쳤는데 알려줬나:   예(=실패) / 아니오(=성공)
→아니오

(4) 글자를 치니까 알려줬나:        예(=성공) / 아니오(=실패)
→예

알려줄 때 뭐라고 했나:
→👁 '메모장' 창에서 '글자 생김'을(를) 봤어요.
케이크 퍼먹고 싶다. 혼자서 먹고싶다
— 화면을 보고 판단한 거라 직접 확인해 주세요. 감시는 여기서 멈출게요.

결과:  성공 
메모: 내가 쓴 내용 그대로임
```

> **둘 다 봐야 합니다.** 안 부르게만 고치면 감시가 죽은 것이고,
> 그건 고친 게 아니라 망가뜨린 겁니다.

## 8. 달력이 자기가 본 것만 말하는가 (1분)

어제 「다른 달력에 있다」고 본 진단은 **재현되지 않았습니다.** 되돌렸습니다.
다만 말이 확인 범위를 넘어서던 것은 그대로라 그것만 고쳤습니다.

### 할 것

일정이 **없는 날**을 물어보세요.

> **"모레 일정 뭐 있어?"** (일정이 없는 날짜로)

### 봐야 할 것

- 「일정이 없어요」가 아니라 **「기본 달력에는 일정이 없어요」** 여야 합니다
- **「다른 달력에 있는 일정은 제가 볼 수 없어요」** 가 같이 나와야 합니다
- 🔑 일정이 **있는** 날은 예전처럼 내용이 나와야 합니다 (하나만 더 물어봐 주세요)

### 적어 주실 것

```
없는 날 답:
→ 10월 2일에는 기본 캘린더에 일정이 없네요.(맞)

있는 날 답 (여전히 잘 나오나):
→
내일은 10월 1일이고, 6개의 일정이 있어요. 지도교수미팅, 똥싸기, 배고프기, 군대가기, 다이어트하기, 책읽기네요.(맞긴 함)

결과:  성공

```
