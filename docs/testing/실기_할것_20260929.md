# 실기 — 내가 할 것만 (2026-09-29)

이 문서만 보고 하면 됩니다. 순서대로 하시면 됩니다.
결과는 `성공 / 실패` 중 하나에 표시하고, 할 말이 있으면 메모에 적어 주세요.
애매하면 `애매` 라고 쓰셔도 됩니다 — 그게 더 정확한 답일 때가 많습니다.

전체 약 30분. 그중 10분은 기다리는 시간이라 그 동안 딴 일 하시면 됩니다.

```

- 음악이나 영상 하나 (5번에서 씁니다)

```

## 1. 가만히 두면 혼자 깨는가 (10분 — 걸어두고 딴 일 하기)

이번 실기에서 **가장 중요한 항목**입니다. 전시회 부스에서 아무도 안 불렀는데
혼자 깨어나면 그게 제일 곤란한 증상이라서요.

### 할 것

마이크를 켜 둔 채로 **10분 동안 평소처럼 컴퓨터를 쓰세요.**
유튜브를 보셔도 되고, 문서 작업을 하셔도 되고, 통화를 하셔도 됩니다.

- **Pluiz 를 부르지 마세요.** 그게 이 항목의 전부입니다.
- 조용히 있을 필요 없습니다. 오히려 **평소처럼 소리가 나는 게 좋습니다** — 부스가 그렇거든요.

10분이 지나면 다음으로 넘어가시면 됩니다. 몇 번 깼는지는 제가 로그로 셉니다.

### 적어 주실 것

```
10분 동안 뭘 하고 있었나 (예: 유튜브 봄 / 문서 작업 / 통화 / 조용했음)
→ 혼잣말 + 노트북 작업

혼자 깨는 걸 눈치챘나 (창이 뜨거나 소리가 났나)
→ 애초에 창이 띄워져 있고 다시 업줄어들게 할 수 없어서 불편하게 보인다

결과:  성공 / 실패 / 애매
메모: 완전 실패. 그냥 계속 깨어나고 심지어 혼잣말 같은거 명령으로 인식돼서 실행됨. 계속 말 한 게 아니라 뜨문뜨문 했는데도 이렇게 오탐지됨. 34-35번정도 깨어난 듯. 계속 말 하면 이것보다 훨씬 많이 오탐지될 것 같다.
```

> 왜 이걸 적어야 하나: 「10분에 4번 깼다」는 숫자만으로는 못 읽습니다.
> 조용한 방이었는지 영상을 틀어놨는지에 따라 뜻이 완전히 달라져서요.

## 5. "메일 오면 알려줘" — 말이 제대로 들리나 (1분)

어제 이게 **「내일 오면 알려줘」, 「매일 오면 알려줘」** 로 세 번 연속 잘못 들렸습니다.

「내일」이나 「매일」로 적혔으면 그게 어제와 같은 증상입니다.

**여기서 성공했으면 6번은 건너뛰지 마시고 그대로 이어서 하세요** — 방금 건 게 6번에 쓰입니다.

## 11. 오늘 일정이 어느 달력에 있나 (2분 — 브라우저)

**다른 달력에 있는 것 같은데, 프로그램이 그걸 확인할 권한이 없습니다.** 그래서 여쭙습니다.

### 할 것

1. [calendar.google.com](https://calendar.google.com) 을 엽니다
2. 왼쪽 「내 캘린더」 목록을 봅니다
3. **오늘 일정이 들어 있는 달력의 이름**을 봅니다

### 적어 주실 것

```
오늘 일정이 들어 있는 달력 이름:
→

그게 기본 달력(qusthdb0@gmail.com)인가, 다른 달력인가:
→정리: 다시 오늘 개별적으로 진행해봤더니 기본 달력 기준으로 제대로 잘 동작함. 일정 있는지 없는지, 몇 시에 뭐가 있는지 같은 것들 인식 함.
```

> 다른 달력이면 제 진단이 맞은 거라 권한을 넓히면 됩니다.
> 기본 달력이 맞다면 제 진단이 틀린 거라 다른 데를 봐야 합니다.
> **어느 쪽이든 오늘 고칠 수 있습니다.**
