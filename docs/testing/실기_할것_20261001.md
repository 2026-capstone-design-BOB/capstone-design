# 실기 — 내가 할 것만 (2026-10-01 · 웨이크워드)

이 문서만 보고 하면 됩니다. 순서대로 하시면 됩니다.
결과는 `성공 / 실패 / 애매` 중 하나에 표시하고, 할 말은 메모에 적어 주세요.

|       | 전          | 후              |
| ----- | ---------- | -------------- |
| 모델    | 9/28 학습본   | **10/01 재학습본** |

| 임계    | 0.62       | **0.80**       |

숫자로는 이렇게 나왔습니다.

|                | 전            | 후           |
| -------------- | ------------:| -----------:|
| 안 불렀는데 혼자 깨는 것 | 시간당 **264회** | 시간당 **15회** |

- 0.6초 늦게 깨는 것이 **답답한가**
- 일곱 번에 한 번 놓치는 것이 **짜증나는가**

> 🚨 숫자가 좋아져도 쓰기 싫으면 되돌립니다. 설정 두 줄이면 됩니다.

## 1. 가까이서 부르기 — 10번 (2분)

### 할 것

평소 앉는 자리(30cm쯤)에서 **"플루이즈"** 를 **정확히 10번** 부릅니다.
한 번 부르고 **5초 쉬고** 다음 번.

🔑 **이번엔 깬 뒤의 느낌도 봐 주세요.** 예전보다 0.6초 늦게 깹니다.

### 적어 주실 것

```
부른 횟수:  10 번

체감상 몇 번 깼나:9
→

🔑 0.6초 늦는 게 느껴지나 / 답답한가:
→ 매번은 아닌데 간헐적으로 조금 체감될 수준으로만 느려진게 느껴짐. 근데 심하진 않다

결과:  성공
메모:
```

> 9/30에는 10/10이었습니다. 이번엔 **8~9번이면 예상대다로**입니다(놓침 15%).
> 그보다 적으면 알려 주세요 — 되돌릴 근거가 됩니다.

## 3. 가만히 두면 혼자 깨나 (10분 — 걸어두고 딴 일)

**여기가 이번에 고친 바로 그 자리입니다.**

### 할 것

마이크를 켜 둔 채 **10분 동안 평소처럼** 컴퓨터를 쓰세요.
유튜브, 문서 작업, 통화, 혼잣말 — 뭐든 됩니다. **부르지만 마세요.**

조용할 필요 없습니다. 오히려 평소처럼 소리가 나는 게 좋습니다.

### 적어 주실 것

```
10분 동안 뭘 하고 있었나:
→ 유튜브+노트북작업+혼잣말

혼자 깨는 걸 눈치챘나 / 몇 번쯤:
→ 4번

결과:  성공 
메모: 공부하느라 말은 잘 안하고 유튜브 노래 틀어놓고 간헐적으로 혼잣말 했는데 확실히 덜 깨는게 체감되긴 하는데 그래도 10분동안 말 많이 안 하고 그런 상화에서 노래에 깨기도 하고 내 말에 깬 것 같기도 한데 뭐 암튼 그렇다.
```

> **9/30에는 10분에 34번이었습니다.** 이번엔 **2~3번이면 예상대로**입니다.
> 10번을 넘으면 알려 주세요 — 측정과 실제가 다르다는 뜻입니다.

### 적어 주실 것

```
뭘 틀어놨나:
→ 유튜브 노래

부른 횟수: 5 번 / 체감상 깬 횟수: 3

내 말에 깬 건지 영상 소리에 깬 건지 구분되나:
→ 3분정도 노래 틀어놓았는데 내가 부를 때만 깨긴 했음. 근데 노래가 연속으로 나오니까 웨이크워드로 깼을 때 계속 노래를 입력으로 받으니까 입력 최대 시간 30초동안 계속 노래를 들으려고 함.

결과:  성공
메모: 방금 노래 따라부르는데 한 번 오탐으로 깸..
```

## 6. 🔴 가장 중요한 질문 — 쓰시겠습니까?

숫자가 아니라 **느낌**을 적어 주세요. 이게 되돌릴지 말지를 정합니다.

```
전보다 나아졌다고 느껴지나:
→ 확실히 나아지긴 했다.

0.6초 지연 — 참을 만한가, 거슬리는가:
→ 참을만은 하다

놓치는 것 — 한 번 더 부르면 되니 괜찮은가, 짜증나는가:
→ 깨울 심산으로 불렀을 때 안 깨는 건 솔직히 드물어서 별 생각 없고, 개발하는 입장이라 그런지 혼잣말이나 노래, 주변 소음(말소리도 아닌..)에 깨어날 때 굉장히 짜증난다. 그래도 많이 호전된 것이 느껴지는게 이전 모델에서는 말 한 번 할 때마다 깨는 것 같았는데 지금은 나름 괜찮아졌다고 판단된다.

🔴 전시회 부스에서 이대로 쓰시겠습니까?
   (아니면 버튼·단축키로 말 거는 쪽이 낫겠습니까?)
→ 버튼/단축키를 설정 부분에 넣어서 쓰되, 웨이크워드 더 개선해서 부스에서 쓰고 싶다.
```

> **마지막 줄이 오늘의 핵심입니다.** 부스는 관람객이 계속 떠드는 자리인데,
> 지금 임계로 못 막는 조건이 하필 **「남의 말소리」** 입니다.
> 버튼으로 가면 혼자 깨는 일이 **구조적으로 0** 이 되고, 호출어는
> *"이것도 됩니다"* 로 보여 주면 됩니다. **제품 결정이라 정해 주셔야 합니다.**
