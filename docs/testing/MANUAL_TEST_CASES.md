# Pluiz v2 — 수동 테스트 케이스 (Manual Only)

> **자동 테스트 현황**
>
> - `test_commands.py` — 기능 동작 자동 검증 (앱 실행/파일 생성/보안 필터 등 25개)
> - `test_regression.py` — 회귀·보완 자동 검증 (BUG-01~11 코드 수준, 20개)
>
> **이 문서는 자동 검증이 불가능한 케이스만 포함합니다.**  
> 판단 기준: 기대 동작 항목 **전부** 충족 시 ✅ PASS, 하나라도 미충족 시 ❌ FAIL
