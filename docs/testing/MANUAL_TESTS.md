## 실행 준비

```bash
conda activate pluiz          # ⚠️ 루트 python(anaconda base)엔 langgraph가 없다
launch.bat                    # 서버 + Electron UI 동시 실행
```

> ⚠️ **`start.bat`이 아니다.** `start.bat`은 **서버만** 띄운다(UI 없음).
> 서버를 두 번 띄우지 말 것 — 두 번째 인스턴스가 죽으면서 첫 번째의 토큰 파일을
> 지워 UI를 끊는 사고가 있었다.

**판정**: 기대 동작을 **전부** 충족해야 ✅. 하나라도 어긋나면 ❌ 이고,
**그 증상만** 적어 두면 된다(로그는 `logs/pluiz.log`).
