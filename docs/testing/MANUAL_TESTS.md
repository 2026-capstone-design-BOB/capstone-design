# Pluiz v2 — 수동 테스트 체크리스트

> 자동화할 수 없는 UI/음성/시각적 확인 항목.  
> 서버 + Electron 실행 후 진행: `start.bat`

---

## Sprint 1 & 2 신규 기능 (이번 세션 추가)

### T02 | 캐시 응답 조사 처리

| # | 입력 | 기대 응답 | 확인 |
|---|------|-----------|------|
| 1 | "메모장 열어줘" (캐시 히트) | "메모장**을** 실행했습니다." (을(를) 아님) | ☐ |
| 2 | "계산기 열어줘" (캐시 히트) | "계산기**를** 실행했습니다." | ☐ |
| 3 | "크롬 열어줘" (캐시 히트) | "크롬**을** 실행했습니다." | ☐ |
| 4 | "메모장 꺼줘" | "메모장**을** 종료했습니다." | ☐ |
| 5 | "계산기 꺼줘" | "계산기**를** 종료했습니다." | ☐ |

> 확인 포인트: 응답에 `을(를)` 형태가 나오면 실패.

---

### T03 | 클립보드 읽기 도구

| # | 방법 | 입력 | 기대 응답 | 확인 |
|---|------|------|-----------|------|
| 1 | 텍스트 선택 후 Ctrl+C → Pluiz에 입력 | "클립보드 내용 보여줘" | 복사한 텍스트 표시 | ☐ |
| 2 | 아무것도 복사 안 한 상태 | "클립보드에 뭐 있어?" | "비어있거나..." 메시지 | ☐ |
| 3 | 긴 텍스트(200자+) 복사 후 | "복사한 내용 알려줘" | 앞 200자 + "총 N자" 표시 | ☐ |

---

### T04 | 도구 실행 결과 검증

| # | 상황 | 기대 동작 | 확인 |
|---|------|-----------|------|
| 1 | 존재하지 않는 앱 이름 실행 요청 | "실행 중 문제가 생겼어요" 또는 실패 안내 (성공처럼 "켰어요!" 금지) | ☐ |
| 2 | pyautogui 미설치 상태에서 "엔터 눌러줘" | 오류 메시지 (서버 크래시 없이) | ☐ |

> 확인 포인트: 오류 상황에서 "켰어요!", "완료했어요!" 같은 성공 응답이 나오면 T04 미작동.

---

### T05 | 히스토리 UI

| # | 동작 | 기대 결과 | 확인 |
|---|------|-----------|------|
| 1 | active view에서 📋 버튼 클릭 | 히스토리 탭 열림, 채팅/입력창 숨김 | ☐ |
| 2 | 대화 몇 개 후 히스토리 탭 열기 | 최근 대화 목록 표시 | ☐ |
| 3 | 히스토리 항목 클릭 | 채팅 탭으로 전환 + 해당 명령이 입력창에 채워짐 | ☐ |
| 4 | "전체 삭제" 클릭 + 확인 | 목록 비워짐 | ☐ |
| 5 | 📋 버튼 다시 클릭 | 채팅 탭으로 복귀 | ☐ |
| 6 | 헤더 더블클릭(idle로 축소) 후 다시 active | 히스토리 탭 닫힌 상태로 시작 | ☐ |

---

### T06 | 즐겨찾기 UI

| # | 동작 | 기대 결과 | 확인 |
|---|------|-----------|------|
| 1 | ⭐ 버튼 클릭 | 즐겨찾기 탭 열림 | ☐ |
| 2 | "+ 추가" → 이름 + 명령 입력 → 저장 | 목록에 즐겨찾기 추가됨 | ☐ |
| 3 | 즐겨찾기 항목 클릭 | 채팅 탭으로 전환 + 해당 명령 즉시 전송 | ☐ |
| 4 | 즐겨찾기 항목의 ✕ 버튼 클릭 | 해당 항목 삭제 | ☐ |
| 5 | 앱 재시작 후 즐겨찾기 탭 열기 | 이전에 추가한 항목 유지됨 (영속 저장) | ☐ |
| 6 | 📋/⭐ 탭 동시 열기 시도 | 하나를 열면 다른 탭 자동 닫힘 | ☐ |

## 기존 기능 회귀 테스트

### 앱 제어

| # | 입력 | 기대 결과 | 확인 |
|---|------|-----------|------|
| 1 | "메모장 열어줘" | 메모장 실행 | ☐ |
| 2 | "계산기 꺼줘" | 계산기 종료 | ☐ |
| 3 | "크롬이랑 메모장 열어줘" | 두 앱 모두 실행 (복합 명령) | ☐ |
| 4 | "메모장 최대화해줘" | 메모장 창 최대화 | ☐ |
| 5 | "바탕화면 보여줘" | 모든 창 최소화 | ☐ |

### 음성 입력 + TTS

| # | 동작 | 기대 결과 | 확인 |
|---|------|-----------|------|
| 1 | 🎙️ 클릭 → "메모장 열어줘" 말하기 | STT 인식 후 메모장 실행, TTS 응답 재생 | ☐ |
| 2 | 말하는 중 파형 애니메이션 | 녹음 중 파형 움직임 표시 | ☐ |
| 3 | 8초 카운트다운 링 | 시간 초과 시 자동 전송 | ☐ |
| 4 | 마이크 중 TTS 재생 중이면 | 마이크 시작 시 TTS 중단 | ☐ |

### 볼륨 제어

| # | 입력 | 기대 결과 | 확인 |
|---|------|-----------|------|
| 1 | "볼륨 50으로 맞춰줘" | 볼륨 50%로 변경 | ☐ |
| 2 | "볼륨 올려줘" | 볼륨 증가 | ☐ |
| 3 | "음소거해줘" | 음소거 | ☐ |

### 웹 / 검색

| # | 입력 | 기대 결과 | 확인 |
|---|------|-----------|------|
| 1 | "유튜브에서 아이유 검색해줘" | 유튜브 검색 탭 열림 | ☐ |
| 2 | "강남역 지도 보여줘" | 지도 앱 또는 브라우저에서 강남역 | ☐ |
| 3 | "오늘 날씨 알려줘" | 날씨 정보 텍스트 응답 | ☐ |

### Electron UI

| # | 동작 | 기대 결과 | 확인 |
|---|------|-----------|------|
| 1 | 아이들 pill 클릭 | active view로 확장 | ☐ |
| 2 | 아이들 pill 더블클릭 | active view 확장 + 즉시 녹음 시작 | ☐ |
| 3 | 헤더 더블클릭 | idle pill로 축소 | ☐ |
| 4 | ✕ 버튼 | 앱 완전 종료 | ☐ |
| 5 | ⚙️ 버튼 | API 설정창 열림 | ☐ |

### 보안 필터

| # | 입력 | 기대 결과 | 확인 |
|---|------|-----------|------|
| 1 | "rm -rf / 실행해줘" | ⚠️ 보안 차단 메시지 | ☐ |
| 2 | "C:\Windows\System32 폴더 삭제" | ⚠️ 보안 차단 메시지 | ☐ |

## 실행 방법 요약

```bash
# 자동화 테스트 (서버 없이 정적 검사만)
python test_sprint1_2.py --static

# 자동화 테스트 전체 (서버 실행 후)
python main.py              # 터미널 1
python test_sprint1_2.py    # 터미널 2

# 기존 자동화 테스트 (서버 실행 후)
python test_commands.py

# 전체 실행 (서버 + Electron)
start.bat
```
