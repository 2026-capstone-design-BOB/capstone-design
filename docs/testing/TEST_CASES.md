# Pluiz v2 — 수동 테스트 케이스

> **사전 조건**: `python main.py` 로 서버 실행 후, Electron UI 열기 (`start.bat` 또는 `npm start`)  
> **판단 기준**: 기대 동작 항목 **전부** 충족 시 ✅ PASS, 하나라도 미충족 시 ❌ FAIL  
> **입력 방법**: UI 채팅창 텍스트 입력 (별도 표기 없으면 텍스트)

---

## 1. 서버 & 연결 상태

| ID | 테스트 항목 | 입력/동작 | 기대 동작 | 결과 |
|----|-----------|---------|---------|------|
| C-01 | 서버 정상 시작 | 서버 시작 후 브라우저에서 `http://127.0.0.1:8765/health` 접속 | `{"status":"ok","version":"2.0.0"}` 반환 | |
| C-02 | WebSocket 연결 | UI 실행 | idle pill의 상태 점(●)이 초록색으로 표시됨 | |
| C-03 | 서버 미실행 시 UI | 서버 없이 UI만 실행 | 상태 점이 빨간색, idle hint가 "서버 연결 중..." | |
| C-04 | API 키 미설정 | API 키 없이 서버 실행 | 설정 오버레이가 자동으로 열림, 취소 버튼 없음 | |
| C-05 | API 키 저장 | 설정창에서 provider 선택 후 유효한 키 입력 → "저장하고 시작" | "✓ 저장 완료!" 메시지 → 1초 후 설정창 닫힘 → WS 재연결 | |

## 13. 버그 수정 회귀 테스트

> 이번 수정에서 고친 버그들이 실제로 동작하는지 확인.

| ID | 수정된 버그 | 검증 방법 | 기대 동작 | 결과 |
|----|-----------|---------|---------|------|
| R-01 | BUG-01: session_memory 이중 저장 | `메모장 열어줘` 입력 후 `GET http://127.0.0.1:8765/history` 조회 | history 배열에 동일 항목이 1개만 있음 (2개 아님) | |

| R-03 | BUG-03: 재시도 예외 | 서버 콘솔에서 `[PluizAgent] 히스토리 오염` 로그 발생 시 | 서버가 500 에러 없이 한국어 오류 메시지 반환 | |

| R-07 | BUG-07: SYSTEM_PROMPT 오타 | 해당 없음 (코드 확인으로 대체) | `core/agent.py` SYSTEM_PROMPT에 "볼륨", "닫기"로 수정됨 | |
